### 1. Inicializar el proyecto (Crear `package.json`)

Este es el primer paso para cualquier proyecto de Node.js. Crea el archivo de configuración donde se anotarán tus librerías.


```Bash
npm init --yes
```

### 2. Instalar las dependencias necesarias

Para el código que pusiste al principio (el de los contactos), necesitas instalar **Express** (el framework web) y **Mongoose** (para conectar con MongoDB). Ejecuta:


```Bash
npm install express mongoose
```

_Esto creará la carpeta `node_modules` y añadirá las dependencias a tu `package.json`._

### 3. Ejecutar tu servidor

Una vez que hayas escrito tu código en un archivo (por ejemplo, `prueba.js`), lo lanzas con:


```Bash
node prueba.js
```
