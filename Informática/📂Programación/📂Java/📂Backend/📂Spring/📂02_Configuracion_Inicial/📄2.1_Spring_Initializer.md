## 📄 Archivo 2.1: `Spring_Initializr.md`

### 💡 ¿Qué es esto?

Es la **página web oficial** (start.spring.io) que te genera el proyecto base. En lugar de crear carpetas a mano y configurarlo todo tú (que es un infierno), vas a esta web, eliges lo que quieres y te descargas un `.zip` listo para funcionar.

### 📝 Resumen para tus apuntes:

> **Web:** [https://start.spring.io/](https://start.spring.io/)
> 
> **Pasos clave:**
> 
> 1. **Project:** Elegir **Maven** (es el gestor que descarga las librerías).
>     
> 2. **Language:** Java.
>     
> 3. **Spring Boot:** La última versión estable (que no ponga SNAPSHOT).
>     
> 4. **Metadata:**
>     
>     - _Group:_ El nombre de tu paquete (ej: `com.accesoadatos`).
>         
>     - _Artifact:_ El nombre de tu proyecto (ej: `biblioteca-api`).
>         
> 5. **Dependencias (Lo más importante):** Aquí es donde eliges los "poderes" de tu app.
>     
>     - `Spring Web`: Para hacer APIs y que tenga servidor.
>         
>     - `Spring Data JPA`: Para conectar a BBDD.
>         
>     - `PostgreSQL Driver`: El cable para hablar con Postgres.
>         
>     - `Lombok`: Para escribir menos código (getters/setters).
>

## 📄 Archivo 2.2: `Estructura_Carpetas.md`

### 💡 ¿Por qué es importante?

Spring es muy "cotilla". Cuando arranca, escanea tus carpetas buscando componentes (`@Controller`, `@Service`, etc.). Pero **tiene una regla de oro**: solo mira hacia abajo.

### ⚠️ La Regla de Oro (Pregunta de Examen):

La clase principal (`@SpringBootApplication`) debe estar en la **raíz** de tu paquete.

- ✅ **BIEN:** `com.miempresa.app.Main` puede ver a `com.miempresa.app.controladores.MiController`.
    
- ❌ **MAL:** Si pones el Main dentro de una carpeta hija, no verá lo que esté fuera.
    

### 📝 Resumen para tus apuntes:

Plaintext

```
src/main/java
 └── com.ejemplo.proyecto
      ├── Application.java  <-- ¡EL JEFE! (Main) Aquí empieza todo.
      │
      ├── controladores/    <-- @RestController
      ├── modelos/          <-- @Entity
      ├── repositorios/     <-- @Repository
      └── servicios/        <-- @Service

src/main/resources
 ├── static/                <-- Archivos públicos (imágenes, CSS, JS)
 ├── templates/             <-- HTML (si usas Thymeleaf, pero en API Rest no se usa mucho)
 └── application.properties <-- ¡El panel de control! (BBDD, Puertos...)
```

## 📄 Archivo 2.3: `Application_Properties.md`

### 💡 ¿Qué es esto?

Es el **panel de configuración** de tu aplicación. Aquí es donde le dices a Spring: "Oye, mi base de datos está en esta dirección, mi usuario es este y mi contraseña es aquella".

Antes, en Java clásico, a veces poníamos la contraseña "a pelo" en el código (hardcoded). **¡Eso es pecado mortal!** Aquí se centraliza todo.

### 📝 Resumen para tus apuntes (Snippet de conexión):

Copia esto porque lo usarás siempre en clase:

Properties

```
# 1. Nombre de la aplicación (opcional pero útil)
spring.application.name=mi-api-rest

# 2. Conexión a la Base de Datos (PostgreSQL)
spring.datasource.url=jdbc:postgresql://localhost:5432/NombreDeTuBBDD
spring.datasource.username=postgres
spring.datasource.password=1234
spring.datasource.driver-class-name=org.postgresql.Driver

# 3. Configuración de JPA (Hibernate)
# Muestra las consultas SQL en la consola (útil para depurar)
spring.jpa.show-sql=true
# Detecta el dialecto de SQL automáticamente
spring.jpa.database-platform=org.hibernate.dialect.PostgreSQLDialect

# 4. Puerto del servidor (Por defecto es 8080, cámbialo si quieres)
server.port=8080
```

## 📄 Archivo 2.4: `Dependencias_Maven.md`

### 💡 ¿Qué es esto? (`pom.xml`)

Es tu **lista de la compra**. Maven es como un chef que lee este archivo (`pom.xml`) y dice: "Ah, quieres cocinar una API con Base de Datos... pues necesito descargarme la librería de Hibernate, la de Tomcat y la del Driver".

Tú no te descargas `.jar` de internet manualmente. Tú escribes una línea en este archivo y Maven se lo baja solo.

### 📝 Resumen para tus apuntes:

> **Archivo:** `pom.xml`
> 
> **Sección `<dependencies>`:** Aquí listamos las librerías externas.
> 
> **Las 4 Fantásticas (Las del curso):**
> 
> 1. `spring-boot-starter-web`: Incluye **Tomcat** (servidor) y **Jackson** (para convertir Objetos <-> JSON).
>     
> 2. `spring-boot-starter-data-jpa`: Incluye **Hibernate** y la magia de los Repositorios.
>     
> 3. `postgresql`: El **Driver JDBC**. Sin esto, Java no sabe hablar el idioma de tu base de datos.
>     
> 4. `lombok`: Una herramienta para programadores vagos (buenos). Con poner `@Data` te crea getters, setters y constructores automáticamente.
>
