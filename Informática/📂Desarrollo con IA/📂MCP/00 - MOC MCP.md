> [!abstract] 🔌 Model Context Protocol (MCP)
> MCP es un estándar abierto que actúa como el **"USB-C de la Inteligencia Artificial"**: un protocolo universal que permite que cualquier modelo de IA se conecte a cualquier herramienta, base de datos o servicio externo de forma segura y estandarizada.
> 
> Esta sección cubre MCP de principio a fin: desde la teoría hasta la creación de tu propio servidor en Python.
