# 🎓 GitHub Foundations — Índice General

La certificación **GitHub Foundations** valida el conocimiento fundamental sobre Git, GitHub y las herramientas de colaboración modernas. Es **gratuita para estudiantes** a través del GitHub Student Developer Pack.
