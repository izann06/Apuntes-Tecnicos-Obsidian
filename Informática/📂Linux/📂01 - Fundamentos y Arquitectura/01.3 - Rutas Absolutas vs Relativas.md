# 🧭 Rutas Absolutas vs Relativas

## ¿Qué es una Ruta (Path)?

Una **ruta** es simplemente la **dirección** que describe dónde se encuentra un archivo o directorio dentro del sistema de archivos. Es como la dirección postal de una casa: te dice exactamente cómo llegar desde un punto hasta otro.

En Linux, las rutas se construyen usando la barra oblicua `/` como separador entre directorios. Cada `/` representa un "nivel" más profundo en el árbol de directorios que vimos en [[01.2 - El Árbol de Directorios y File System de Linux]].

Existen dos formas de escribir una ruta:

| Tipo | Empieza desde... | Comienza con... | Ejemplo |
|------|-----------------|-----------------|---------|
| **Ruta Absoluta** | La raíz del sistema `/` | Siempre con `/` | `/home/juan/documentos/notas.txt` |
| **Ruta Relativa** | Tu ubicación actual | Sin `/` inicial | `documentos/notas.txt` o `../maria/fotos/` |

---

## Rutas Absolutas: La Dirección Completa

Una **ruta absoluta** es la dirección **completa y exacta** de un archivo, empezando siempre desde la raíz `/`. No importa dónde estés tú en ese momento dentro del sistema: la ruta absoluta siempre funciona porque describe el camino completo desde el origen.

> [!abstract] 📮 Analogía: La Dirección Postal Completa
> Una ruta absoluta es como dar la dirección postal completa de una casa: **"Calle Mayor 15, 3ºB, Madrid, España, Europa, Planeta Tierra"**. No importa si tú estás en Tokio, Buenos Aires o la Luna: con esa dirección completa, cualquiera puede encontrar la casa. Siempre empieza desde el punto más grande (el "planeta" = la raíz `/`) y va bajando nivel a nivel hasta llegar al destino.

### Características de las Rutas Absolutas

- **Siempre** empiezan con `/` (la raíz)
- **Siempre** funcionan, sin importar tu ubicación actual
- Son **únicas**: solo puede haber un archivo en esa ruta exacta
- Son más **largas** de escribir, pero más **seguras** y predecibles

### Ejemplos Prácticos

```bash
# Mostrar tu ubicación actual:
pwd
# /home/juan

# Ir a una carpeta usando su ruta absoluta (funciona desde CUALQUIER sitio):
cd /home/juan/documentos/proyectos

# Listar el contenido de un directorio con ruta absoluta:
ls /var/log/

# Copiar un archivo usando rutas absolutas:
cp /home/juan/notas.txt /tmp/backup_notas.txt

# Editar un archivo de configuración con ruta absoluta:
sudo nano /etc/hostname

# Ver el contenido de un archivo con ruta absoluta:
cat /etc/passwd
```

> [!tip] ¿Cuándo usar rutas absolutas?
> Usa rutas absolutas cuando:
> - Escribes **scripts de Bash** → [[05.1 - Estructura Básica de un Script en Bash]] (los scripts deben funcionar sin importar desde dónde se ejecuten)
> - Editas **archivos de configuración** del sistema
> - Programas **tareas con Cron** → [[05.6 - Programación de Tareas con Cron (Crontab)]]
> - Quieres **seguridad total** de que estás accediendo al archivo correcto

## Rutas Relativas: La Dirección Desde Donde Estás

Una **ruta relativa** describe el camino **desde tu ubicación actual** (el directorio de trabajo en el que estás ahora). No empieza con `/`, porque no parte de la raíz, sino de "aquí mismo".

> [!abstract] 🗺️ Analogía: Las Indicaciones del Vecino
> Imagina que le preguntas a tu vecino cómo llegar a la panadería. No te va a dar la dirección postal completa ("Calle Secundaria 7, Madrid, España..."). Te va a decir: **"Sal de tu casa, gira a la derecha, camina dos manzanas y es la tercera puerta"**. Esas instrucciones solo funcionan si **partes desde tu casa**. Si estuvieras en otro barrio, esas indicaciones te llevarían a un sitio completamente diferente. Eso es una ruta relativa.

### Características de las Rutas Relativas

- **NO** empiezan con `/`
- **Dependen** de tu ubicación actual (`pwd`)
- Son más **cortas** y cómodas de escribir
- Cambian de significado si cambias de directorio

### Ejemplos Prácticos

```bash
# Supongamos que estás en /home/juan:
pwd
# /home/juan

# Ir a una subcarpeta (relativa a tu posición):
cd documentos
# Ahora estás en /home/juan/documentos

# Listar una subcarpeta sin moverte:
ls proyectos/web/

# Copiar un archivo del directorio actual a una subcarpeta:
cp notas.txt documentos/backup/

# Crear un archivo en una subcarpeta:
touch proyectos/nuevo_archivo.txt
```

## Los Tres Atajos Mágicos: `.`, `..` y `~`

Estos tres caracteres especiales son tus mejores amigos para navegar rápidamente por el sistema de archivos.

### El Punto `.` — Directorio Actual

El punto simple `.` representa **el directorio en el que estás ahora mismo**. Parece inútil al principio, pero tiene usos muy importantes:

```bash
# Ejecutar un script en el directorio actual:
./mi_script.sh
# El ./ le dice a Linux: "busca mi_script.sh AQUÍ, en este directorio"

# Copiar un archivo AL directorio actual:
cp /etc/hostname .
# Copia el archivo 'hostname' al directorio donde estás ahora

# Mover un archivo AL directorio actual:
mv /tmp/descarga.zip .
```

> [!tip] ¿Por qué necesitas `./` para ejecutar scripts?
> Cuando escribes un comando como `ls`, Linux lo busca automáticamente en los directorios del PATH del sistema (generalmente `/usr/bin`, `/usr/local/bin`, etc.). Tu directorio actual **no** está en el PATH por seguridad. Por eso, para ejecutar un script que está "aquí mismo", necesitas decirle explícitamente a Linux "búscalo aquí" con `./`. Más sobre scripts en [[05.1 - Estructura Básica de un Script en Bash]].

### Los Dos Puntos `..` — Directorio Padre

Los dos puntos `..` representan **el directorio que está un nivel arriba** (el directorio padre). Es como "subir un piso" en un edificio.

```bash
# Estás en /home/juan/documentos/proyectos
pwd
# /home/juan/documentos/proyectos

# Subir un nivel (al directorio padre):
cd ..
pwd
# /home/juan/documentos

# Subir dos niveles de golpe:
cd ../..
pwd
# /home/juan

# Acceder a un directorio "hermano" (subir y bajar):
# Estás en /home/juan/documentos, quieres ir a /home/juan/descargas
cd ../descargas
pwd
# /home/juan/descargas

# Copiar un archivo del directorio padre:
cp ../archivo_arriba.txt .
```

> [!abstract] 🏢 Analogía: El Ascensor del Edificio
> Piensa en el sistema de archivos como un edificio de oficinas:
> - `.` es el **piso donde estás ahora**
> - `..` es **subir un piso** (al padre)
> - `../..` es **subir dos pisos**
> - `../../otro_piso/oficina` es **subir dos pisos y luego bajar por otro pasillo**

### La Virgulilla `~` — Tu Home Dulce Home

La virgulilla `~` (también llamada "colita de chancho" o tilde de la eñe) es un atajo que siempre apunta a la **carpeta home del usuario actual**. Es como un botón de "volver a casa" instantáneo.

```bash
# Ir a tu carpeta home desde CUALQUIER lugar:
cd ~
pwd
# /home/juan

# Abreviatura aún más corta (cd sin argumentos hace lo mismo):
cd
pwd
# /home/juan

# Usar ~ en medio de rutas:
ls ~/documentos/
# Lista /home/juan/documentos/

# Copiar un archivo a tu home:
cp /etc/hostname ~/

# Acceder al home de OTRO usuario (si tienes permisos):
ls ~maria
# Lista /home/maria/

# Editar tu archivo de configuración de Bash:
nano ~/.bashrc
# Edita /home/juan/.bashrc
```

> [!tip] `cd` solito = `cd ~`
> Escribir `cd` sin ningún argumento es equivalente a `cd ~`. Te lleva directamente a tu carpeta home. Es el atajo más rápido para "volver a casa".

## Tabla Comparativa Completa

| Concepto | Símbolo | Significado | Ejemplo (estando en `/home/juan/docs`) |
|----------|---------|-------------|----------------------------------------|
| **Ruta Absoluta** | Empieza con `/` | Camino completo desde la raíz | `/home/juan/docs/notas.txt` |
| **Ruta Relativa** | Sin `/` inicial | Camino desde tu posición actual | `notas.txt` o `proyectos/web/` |
| **Directorio Actual** | `.` | Aquí mismo | `./script.sh` |
| **Directorio Padre** | `..` | Un nivel arriba | `cd ..` → `/home/juan` |
| **Dos niveles arriba** | `../..` | Dos niveles arriba | `cd ../..` → `/home` |
| **Home del usuario** | `~` | Tu carpeta personal | `cd ~` → `/home/juan` |
| **Home de otro** | `~usuario` | Home de otro usuario | `ls ~maria` → `/home/maria` |
| **Directorio anterior** | `cd -` | El último directorio donde estabas | `cd -` → vuelve al anterior |

## Ejemplos de Conversión: Absoluta ↔ Relativa

Supongamos que tu ubicación actual es `/home/juan/documentos`:

| Ruta Absoluta | Ruta Relativa Equivalente |
|--------------|---------------------------|
| `/home/juan/documentos/notas.txt` | `notas.txt` o `./notas.txt` |
| `/home/juan/documentos/proyectos/web/` | `proyectos/web/` |
| `/home/juan/descargas/` | `../descargas/` |
| `/home/maria/` | `../../maria/` |
| `/etc/passwd` | `../../../etc/passwd` |
| `/home/juan/` | `..` o `~/` |

## Casos de Uso en el Día a Día

### Caso 1: Organizando archivos de un proyecto

```bash
# Crear estructura de un proyecto con rutas relativas:
mkdir -p proyecto/{src,docs,tests,config}
# Crea:
#   proyecto/
#   ├── src/
#   ├── docs/
#   ├── tests/
#   └── config/

cd proyecto
touch src/main.py docs/README.md tests/test_main.py config/settings.json
```

### Caso 2: Navegando rápido con `cd -`

```bash
# Estás editando en tu proyecto:
pwd
# /home/juan/proyectos/web-app/src

# Necesitas revisar un log rápidamente:
cd /var/log
cat syslog | tail -5

# Volver al directorio anterior instantáneamente:
cd -
pwd
# /home/juan/proyectos/web-app/src
# ¡De vuelta en un solo comando!
```

### Caso 3: Scripts con rutas absolutas

```bash
#!/bin/bash
# Los scripts SIEMPRE deben usar rutas absolutas para ser fiables:

# ✅ CORRECTO - Ruta absoluta (funciona desde cualquier lugar):
BACKUP_DIR="/home/juan/backups"
LOG_FILE="/var/log/mi_script.log"

# ❌ INCORRECTO - Ruta relativa (falla si ejecutas desde otro directorio):
BACKUP_DIR="backups"
LOG_FILE="logs/mi_script.log"
```

> [!warning] Rutas en scripts de Bash y Cron
> Cuando escribas scripts que se ejecuten automáticamente (especialmente con Cron → [[05.6 - Programación de Tareas con Cron (Crontab)]]), **siempre usa rutas absolutas**. Las tareas de Cron se ejecutan desde el directorio home de root por defecto, así que una ruta relativa como `backups/` apuntaría a `/root/backups/`, no a donde tú esperas.

## Ejercicio Mental Rápido

```bash
# Ubicación actual: /home/juan/proyectos/web

# ¿A dónde te llevan estos comandos?
cd ..                    # → /home/juan/proyectos
cd ../..                 # → /home/juan
cd ~                     # → /home/juan
cd /                     # → /  (la raíz)
cd ~/documentos          # → /home/juan/documentos
cd -                     # → /home/juan/proyectos/web (el anterior)
cd ../../descargas       # → /home/juan/descargas
```
