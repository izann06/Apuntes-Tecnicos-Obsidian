# 🚀 Warp Terminal: Entorno Integrado con IA

## ¿Qué es Warp?

**Warp** es una terminal moderna que se define como un **Agentic Development Environment** (Entorno de Desarrollo Agéntico). Va mucho más allá de una terminal clásica: integra inteligencia artificial, bloques visuales, workflows reutilizables e indexación de código directamente en la experiencia de línea de comandos.

> [!abstract] 🧠 Analogía: De la Máquina de Escribir al Procesador de Texto
> Si la terminal clásica (Bash en una ventana negra) es como una **máquina de escribir mecánica**, Warp es como pasar a **Google Docs**: tienes autocompletado inteligente, sugerencias contextuales, historial organizado visualmente, y un asistente de IA integrado que te ayuda a escribir y corregir. La esencia es la misma (escribir texto), pero la experiencia es radicalmente diferente.

---

## División Inteligente por Bloques

Una de las características más distintivas de Warp es que organiza la terminal en **bloques visuales**. Cada comando y su salida forman un bloque independiente que puedes:

- **Seleccionar** individualmente con un clic
- **Copiar** la salida de un comando específico sin seleccionar texto con el ratón
- **Compartir** un bloque específico con compañeros
- **Buscar** dentro de un bloque concreto

```
┌─────────────────────────────────────────┐
│  $ ls -la /var/log                       │  ← Bloque 1
│  total 4096                              │
│  drwxr-xr-x  12 root root 4096 ...      │
│  -rw-r-----   1 root adm  12345 syslog  │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  $ df -h                                 │  ← Bloque 2
│  Filesystem  Size  Used Avail Use%       │
│  /dev/sda1   100G  45G   55G  45%        │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  $ ping -c 3 google.com                  │  ← Bloque 3
│  64 bytes from 142.250.200.46: ...       │
│  3 packets transmitted, 3 received       │
└─────────────────────────────────────────┘
```

> [!tip] Adiós al scroll infinito
> En una terminal tradicional, cuando ejecutas muchos comandos, la salida es un río continuo de texto donde es difícil distinguir dónde termina un comando y empieza otro. Los bloques de Warp separan visualmente cada comando, haciendo que la terminal sea **legible y organizada**.

## El Modo Agente de IA

La característica estrella de Warp es su **agente de IA integrado** que puede:

### 1. Generar Comandos con `#`

Escribe una almohadilla `#` seguida de una descripción en lenguaje natural, y la IA genera el comando correspondiente:

```bash
# buscar todos los archivos .log mayores de 100MB
# → find / -name "*.log" -size +100M

# comprimir la carpeta proyectos en un tar.gz
# → tar -czf proyectos.tar.gz proyectos/

# ver los 10 procesos que más CPU consumen
# → ps aux --sort=-%cpu | head -11

# cambiar los permisos de todos los .sh a ejecutable recursivamente
# → find . -name "*.sh" -exec chmod +x {} \;
```

### 2. Explicar Errores

Cuando un comando falla, Warp puede **explicar el error** y sugerir soluciones:

```
$ apt install htop
E: Could not open lock file - Permission denied

┌─ 🤖 Warp AI ────────────────────────────────────┐
│ Este error ocurre porque 'apt install' necesita   │
│ privilegios de administrador.                      │
│                                                    │
│ Solución: Ejecuta el comando con 'sudo':           │
│ $ sudo apt install htop                            │
└────────────────────────────────────────────────────┘
```

### 3. Dar Contexto con `@`

Puedes usar la arroba `@` para dar contexto adicional al agente de IA:

```bash
# @archivo.py explica qué hace esta función
# @README.md genera un resumen de este proyecto
# @error.log analiza los errores más frecuentes
```

## Workflows: Flujos de Trabajo Reutilizables

Los **Workflows** de Warp son secuencias de comandos parametrizados que puedes guardar y reutilizar. Son como **plantillas de comandos** con variables que completas al ejecutarlos.

### Crear un Workflow

```yaml
# Workflow: Deploy a producción
name: deploy_produccion
command: |
  cd {{directorio_proyecto}}
  git pull origin {{rama}}
  npm install
  npm run build
  sudo systemctl restart {{servicio}}
parameters:
  - name: directorio_proyecto
    default: /var/www/mi-app
  - name: rama
    default: main
  - name: servicio
    default: mi-app
```

### Ejecutar un Workflow

Al ejecutar el workflow, Warp te muestra un formulario interactivo para rellenar las variables entre `{{llaves}}`:

```
┌─ Workflow: deploy_produccion ──────────────────┐
│                                                  │
│  directorio_proyecto: [/var/www/mi-app        ] │
│  rama:                [main                    ] │
│  servicio:            [mi-app                  ] │
│                                                  │
│  [Ejecutar]  [Cancelar]                          │
└──────────────────────────────────────────────────┘
```

### Workflows Útiles para SysAdmins

```yaml
# Workflow: Backup rápido
name: backup_rapido
command: tar -czf /backups/{{nombre}}_$(date +%Y%m%d).tar.gz {{directorio}}
parameters:
  - name: nombre
    description: Nombre del backup
  - name: directorio
    description: Directorio a respaldar

# Workflow: Buscar en logs
name: buscar_logs
command: grep -rn "{{patron}}" /var/log/{{archivo_log}} | tail -{{lineas}}
parameters:
  - name: patron
    description: Patrón a buscar
  - name: archivo_log
    default: syslog
  - name: lineas
    default: 20

# Workflow: Crear usuario completo
name: crear_usuario
command: |
  sudo adduser {{usuario}}
  sudo usermod -aG {{grupos}} {{usuario}}
  echo "Usuario {{usuario}} creado y añadido a {{grupos}}"
parameters:
  - name: usuario
  - name: grupos
    default: sudo,developers
```

## Modo Automático y Autodetección

Warp tiene un **modo automático** que detecta el contexto de lo que estás haciendo y ofrece sugerencias inteligentes:

- **Autocompletado contextual**: No solo completa nombres de archivos, sino que sugiere opciones y flags basándose en el comando que estás escribiendo
- **Detección de errores comunes**: Si escribes `rm -rf /` (o algo peligroso), Warp te advierte antes de ejecutar
- **Historial inteligente**: Busca en tu historial con contexto semántico, no solo por coincidencia de texto

## Indexación de Código

Warp puede **indexar tu repositorio de código** para que la IA entienda el contexto de tu proyecto cuando le haces preguntas:

```bash
# Con el proyecto indexado, puedes preguntar cosas como:
# "¿Dónde se define la función de autenticación?"
# "¿Qué archivos importan este módulo?"
# "Genera un test para la clase UserService"
```

## ¿Por Qué Considerar Warp?

| Característica | Terminal Clásica | Warp |
|---------------|-----------------|------|
| **Interfaz** | Texto plano continuo | Bloques visuales organizados |
| **Autocompletado** | Básico (Tab) | Inteligente y contextual |
| **Ayuda con errores** | Buscas en Google | IA te explica y sugiere |
| **Generar comandos** | Tú lo escribes todo | `#` + descripción natural |
| **Workflows** | Scripts manuales | Plantillas interactivas |
| **Historial** | `history \| grep` | Búsqueda semántica |
| **Colaboración** | Copiar/pegar texto | Compartir bloques |

> [!warning] Warp requiere crear una cuenta
> Warp es gratuito para uso individual pero requiere crear una cuenta. Algunos usuarios prefieren no depender de un servicio externo para su terminal. Si prefieres una alternativa completamente offline y open source, considera [[06.2 - Transición a ZSH y Oh My ZSH]] con plugins como `zsh-autosuggestions`.
