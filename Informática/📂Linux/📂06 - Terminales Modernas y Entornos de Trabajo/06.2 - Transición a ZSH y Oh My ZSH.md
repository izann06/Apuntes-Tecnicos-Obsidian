# 💎 Transición a ZSH y Oh My ZSH

## ¿Qué es ZSH?

**ZSH** (Z Shell) es un shell de comandos que extiende las capacidades de Bash con características modernas. Si Bash es un **coche fiable y funcional**, ZSH es la **versión premium con extras de lujo**: autocompletados avanzados, corrección ortográfica, temas visuales, y mucho más.

> [!tip] macOS ya usa ZSH por defecto
> Desde macOS Catalina (2019), Apple cambió el shell por defecto de Bash a ZSH. Si usas macOS, ya estás usando ZSH sin saberlo.

### ¿Por Qué Pasar de Bash a ZSH?

| Característica | Bash | ZSH |
|---------------|------|-----|
| **Autocompletado** | Básico (Tab) | Avanzado con menú de opciones navegable |
| **Corrección ortográfica** | ❌ No | ✅ Sugiere correcciones (`gut` → `git`) |
| **Navegación de historial** | Flechas ↑↓ | Búsqueda contextual (escribe `git` + ↑ = solo comandos git) |
| **Globbing avanzado** | Básico (`*`, `?`) | Extendido (`**/*.txt` busca recursivamente) |
| **Temas y plugins** | Manuales | Framework "Oh My ZSH" con cientos de opciones |
| **Prompts personalizados** | Configuración manual | Temas instantáneos (Powerlevel10k, agnoster...) |
| **Compatibilidad con Bash** | — | ✅ Casi 100% compatible con scripts Bash |
| **Compartir historial** | ❌ No entre terminales | ✅ Historial compartido entre todas las sesiones |

## Instalar ZSH

```bash
# Verificar si ya tienes ZSH:
zsh --version
# zsh 5.9 (x86_64-ubuntu-linux-gnu)

# Instalar ZSH (Debian/Ubuntu):
sudo apt install zsh

# Instalar ZSH (Fedora):
sudo dnf install zsh

# Instalar ZSH (Arch):
sudo pacman -S zsh

# Cambiar tu shell por defecto a ZSH:
chsh -s $(which zsh)
# Necesitas cerrar sesión y volver a entrar para que surta efecto

# Verificar tu shell actual:
echo $SHELL
# /usr/bin/zsh (o /bin/zsh)
```

## Oh My ZSH: El Framework que Vitamina tu Terminal

**Oh My ZSH** es un framework open source para gestionar la configuración de ZSH. Te da acceso a cientos de **temas visuales** y **plugins** que transforman completamente tu experiencia en la terminal.

### Instalación

```bash
# Instalar Oh My ZSH (un solo comando):
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

# o con wget:
sh -c "$(wget -O- https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

# Después de instalar, tu terminal cambiará de apariencia instantáneamente
```

### El Archivo de Configuración: `~/.zshrc`

Oh My ZSH se configura editando `~/.zshrc` (equivalente al `~/.bashrc` de Bash → [[05.1 - Estructura Básica de un Script en Bash]]):

```bash
nano ~/.zshrc
```

## Temas: Cambia la Apariencia de tu Terminal

Oh My ZSH viene con más de 150 temas preinstalados. Cambiar de tema es tan simple como editar una línea en `~/.zshrc`:

```bash
# En ~/.zshrc, busca la línea ZSH_THEME y cámbiala:
ZSH_THEME="robbyrussell"    # Tema por defecto (simple y limpio)
ZSH_THEME="agnoster"        # Popular, muestra rama de git, usuario, estado
ZSH_THEME="powerlevel10k/powerlevel10k"  # El más popular y personalizable
ZSH_THEME="fino"            # Minimalista y elegante
ZSH_THEME="random"          # ¡Un tema aleatorio cada vez que abres la terminal!
```

### Powerlevel10k (El Mejor Tema)

**Powerlevel10k** es el tema más popular y personalizable para ZSH. Muestra información contextual como la rama de Git, el estado del repositorio, la versión de Node/Python, el tiempo de ejecución del último comando, y mucho más.

```bash
# Instalar Powerlevel10k:
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git \
  ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k

# En ~/.zshrc:
ZSH_THEME="powerlevel10k/powerlevel10k"

# Aplicar cambios:
source ~/.zshrc
# Se abrirá un asistente de configuración interactivo
```

> [!tip] Fuentes Nerd Font
> Para que los iconos y símbolos de Powerlevel10k se vean correctamente, necesitas instalar una **Nerd Font** (fuentes con iconos integrados). Las más populares son:
> - **MesloLGS NF** (recomendada por Powerlevel10k)
> - **FiraCode Nerd Font**
> - **JetBrains Mono Nerd Font**

## Plugins: Superpoderes para tu Terminal

Los plugins añaden funcionalidades extra a ZSH. Se activan añadiéndolos a la lista de plugins en `~/.zshrc`:

```bash
# En ~/.zshrc:
plugins=(
    git
    zsh-autosuggestions
    zsh-syntax-highlighting
    docker
    kubectl
    sudo
    history
    colored-man-pages
)
```

### Los Plugins Más Útiles

#### `zsh-autosuggestions` — Sugerencias en Tiempo Real

Mientras escribes, te muestra en gris el último comando que coincide con lo que estás escribiendo. Presiona la flecha → para aceptar la sugerencia.

```bash
# Instalar:
git clone https://github.com/zsh-users/zsh-autosuggestions \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions

# Ejemplo de uso:
$ git c                     # Empiezas a escribir
$ git commit -m "fix: bug"  # Aparece en gris la sugerencia del historial
# Presiona → para aceptar, o sigue escribiendo para ignorar
```

#### `zsh-syntax-highlighting` — Colores de Sintaxis

Colorea los comandos **mientras los escribes**: verde si el comando existe, rojo si no. Te avisa de errores antes de presionar Enter.

```bash
# Instalar:
git clone https://github.com/zsh-users/zsh-syntax-highlighting \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting

# Ejemplo:
$ ls          # Se muestra en VERDE (comando válido)
$ lss         # Se muestra en ROJO (comando no encontrado)
$ cat arch    # "cat" en verde, "arch" subrayado si existe
```

#### `sudo` — Doble Escape para sudo

Presiona `Esc` dos veces para añadir `sudo` al inicio del comando actual o del anterior.

```bash
$ apt install htop
# "Permission denied"
# Presiona Esc Esc:
$ sudo apt install htop    # ¡sudo añadido automáticamente!
```

#### `git` — Alias para Git

Añade decenas de alias útiles para Git:

```bash
# Algunos alias que activa:
gst    # git status
ga     # git add
gc     # git commit
gp     # git push
gl     # git pull
gd     # git diff
gco    # git checkout
gb     # git branch
glog   # git log --oneline --decorate --graph
```

## Características Avanzadas de ZSH

### Globbing Recursivo

```bash
# Buscar recursivamente todos los .py en subcarpetas:
ls **/*.py
# (En Bash necesitarías: find . -name "*.py")

# Listar todos los archivos .log en cualquier subdirectorio:
ls **/*.log

# Borrar todos los .tmp recursivamente:
rm **/*.tmp
```

### Corrección Ortográfica

```bash
$ gut status
# zsh: correct 'gut' to 'git' [nyae]?
# n = no, y = yes, a = abort, e = edit
```

### Historial Compartido

```bash
# En ZSH, el historial se comparte entre TODAS las terminales abiertas.
# Si escribes un comando en la terminal 1, puedes buscarlo con ↑ en la terminal 2.

# Búsqueda contextual con flechas:
# Escribe "docker" y luego presiona ↑
# Solo muestra comandos anteriores que empiezan con "docker"
```

### Navegación de Directorios sin `cd`

```bash
# En ZSH, puedes navegar escribiendo solo el nombre del directorio:
/etc                    # Equivalente a: cd /etc
..                      # Equivalente a: cd ..
~/proyectos             # Equivalente a: cd ~/proyectos

# Activar en ~/.zshrc:
setopt AUTO_CD
```

## Configuración Completa Recomendada

```bash
# ~/.zshrc completo recomendado:

# ── Ruta de Oh My ZSH ──
export ZSH="$HOME/.oh-my-zsh"

# ── Tema ──
ZSH_THEME="powerlevel10k/powerlevel10k"

# ── Plugins ──
plugins=(
    git
    zsh-autosuggestions
    zsh-syntax-highlighting
    sudo
    colored-man-pages
    history
    docker
    extract
)

# ── Cargar Oh My ZSH ──
source $ZSH/oh-my-zsh.sh

# ── Alias personalizados ──
alias ll="ls -alh"
alias la="ls -la"
alias ..="cd .."
alias ...="cd ../.."
alias actualizar="sudo apt update && sudo apt upgrade -y"
alias puertos="sudo ss -tlnp"
alias disco="df -h"
alias mem="free -h"

# ── Variables de entorno ──
export EDITOR="nano"
export LANG="es_ES.UTF-8"
export PATH="$HOME/.local/bin:$PATH"

# ── Opciones de ZSH ──
setopt AUTO_CD           # cd sin escribir "cd"
setopt CORRECT           # Corrección ortográfica
setopt SHARE_HISTORY     # Compartir historial entre terminales
setopt HIST_IGNORE_DUPS  # Ignorar duplicados en historial
```

```bash
# Aplicar los cambios:
source ~/.zshrc
```
