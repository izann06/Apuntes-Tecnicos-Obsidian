# 07.4 — Anatomía de Pacman (Comandos Básicos)

`pacman` es el gestor de paquetes por excelencia de Arch Linux y CachyOS. Su sintaxis asusta un poco al principio porque usa parámetros con letras en lugar de palabras, pero siempre sigue el formato:
`sudo pacman -[Letra_Mayúscula_Principal][letras_minúsculas_secundarias]`

Aquí tienes los comandos del día a día que necesitas aprender.

## ⬇️ 1. Instalar Programas: `-S` (Sync)

La letra `S` mayúscula significa **Sync** (Sincronizar). Le dice a pacman que sincronice y descargue un paquete desde los servidores oficiales hacia tu ordenador.

```bash
# Instalar un solo programa (ej: docker)
sudo pacman -S docker

# Instalar varios programas a la vez, separados por un espacio
sudo pacman -S discord vlc obs-studio
```

## 🗑️ 2. Desinstalar Programas: `-R` (Remove)

La letra `R` mayúscula significa **Remove** (Eliminar). Pero **¡OJO!**, si usas solo `-R`, estás desinstalando mal el software en Linux. Dejarás dependencias huérfanas ocupando espacio en tu disco duro (librerías que se instalaron obligatoriamente junto al programa, pero que sin él ya no sirven de nada) y archivos de configuración basura.

```bash
# ❌ MAL (Deja dependencias huérfanas y configuraciones en el sistema):
sudo pacman -R flameshot

# ✅ BIEN (Borra el programa Y las dependencias que ya nadie usa):
# La 's' minúscula significa borrar dependencias no necesarias (unneeded)
sudo pacman -Rs flameshot

# 🌟 PERFECTO (Borra el programa, las dependencias inútiles Y sus archivos de configuración global):
# La 'n' minúscula le dice que elimine también los archivos de configuración (nosave)
sudo pacman -Rns flameshot
```

> [!tip] La mejor forma de borrar: `-Rns`
> Acostúmbrate siempre, desde el primer día, a borrar usando `sudo pacman -Rns <paquete>`. La `s` limpia las dependencias huérfanas y la `n` limpia los archivos de configuración globales. Es el secreto absoluto para mantener un sistema Linux rápido y limpio durante años sin tener que formatear.

## 📦 3. Instalar un paquete descargado de internet: `-U` (Upgrade/Local)

A veces descargas un programa directamente de la página web de un desarrollador y te sueltan un archivo suelto que termina en `.pkg.tar.zst`. Para instalar un paquete local (offline) que tienes en tu carpeta de Descargas, usas la letra `U`.

```bash
# Instalar un paquete que ya tienes descargado localmente
sudo pacman -U /ruta/hacia/el/archivo/programa-version1.pkg.tar.zst
```

## 🔍 Otros Comandos de Búsqueda y Mantenimiento

Para no perderte cuando no sepas si algo está instalado o si existe en los servidores:

| Comando Pacman | Para qué sirve |
| :--- | :--- |
| `pacman -Ss <nombre>` | **Buscar** un programa en los servidores oficiales de internet. |
| `pacman -Qs <nombre>` | **Buscar** si tienes un programa *ya instalado* actualmente en tu PC. |
| `pacman -Qdt` | **Listar las dependencias huérfanas** de tu sistema (basura acumulada). |
| `pacman -Qi <nombre>` | **Ver información detallada** (versión, tamaño, autor) de un paquete instalado. |
