# 07.2 — Ecosistemas y Familias de Linux

Linux no es un solo sistema operativo, es solo un "núcleo" (kernel). Sobre él, distintas comunidades han construido versiones completas y personalizadas llamadas **Distribuciones** (o distros). Existen tres grandes familias principales en el mundo Linux, cada una con su propio formato de paquete y su propio programa gestor.

## 1. Familia Debian / Ubuntu
La familia más popular para servidores web y ordenadores de uso general. Ubuntu, Linux Mint o Pop!_OS pertenecen a ella.
- **Formato de archivo:** `.deb`
- **Gestor de paquetes:** `apt` (Advanced Package Tool)
- **Ejemplo de instalación:** `sudo apt install firefox`

## 2. Familia Red Hat / Fedora
Muy popular en entornos empresariales (bancos, multinacionales) y servidores profesionales.
- **Formato de archivo:** `.rpm` (Red Hat Package Manager)
- **Gestor de paquetes:** `dnf` *(este es el gestor al que te referías al mencionar "rdf")*.
- **Ejemplo de instalación:** `sudo dnf install firefox`

## 3. Familia Arch Linux / CachyOS / Manjaro
La familia pensada para entusiastas de la informática, personalización extrema y máximo rendimiento. Es a la que pertenece tu sistema operativo actual (**CachyOS**).
- **Formato de archivo:** `.pkg.tar.zst` (paquetes altamente comprimidos con zstd)
- **Gestor de paquetes:** `pacman` (Package Manager)
- **Ejemplo de instalación:** `sudo pacman -S firefox`

## 🌐 Herramientas de Descarga: Curl, wget, pacman, yay... ¿Cuál usar?

Como estás aprendiendo, es normal frustrarse buscando cómo instalar cosas en internet. A veces ves un tutorial que usa `curl`, otro usa `yay`, otro usa `wget`... ¿Cuál toca usar en cada momento?

Aquí tienes la guía definitiva:

| Herramienta | Qué hace | Cuándo debes usarla |
| :--- | :--- | :--- |
| **`curl`** | Transfiere datos desde una URL directamente a tu terminal (o a un archivo). | Cuando sigues un tutorial oficial y te dicen "ejecuta este script para empezar" (ej. `curl -O https://sitio.com/script.sh`). Sirve para bajar cosas sueltas de internet. |
| **`wget`** | Muy similar a `curl`. Descarga archivos de internet a tu ordenador. | Cuando tienes un link directo y quieres descargar un `.zip` o una imagen usando la terminal en lugar del navegador web. |
| **`pacman`** | Es el **gestor oficial** de tu sistema Arch/CachyOS. | Para instalar los programas **oficiales**, seguros y testeados. Programas comunes de tu día a día (Discord, Firefox, Steam, VLC, GIMP). |
| **`yay` o `paru`** | Son gestores comunitarios, también llamados **AUR Helpers**. | Cuando el programa que buscas NO ESTÁ en los servidores oficiales (ej. Spotify, Google Chrome) y tienes que instalarlo descargando las "recetas" de la comunidad. |

> [!tip] En resumen
> - **¿Programa famoso oficial?** → `sudo pacman -S programa`
> - **¿Programa privativo o de la comunidad?** → `paru -S programa` (o `yay`). ¡Sin sudo!
> - **¿Archivo suelto / script de internet?** → `curl` o `wget`
