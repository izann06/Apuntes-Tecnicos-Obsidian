# 07.3 — El Modelo Arch Linux y CachyOS

Al usar **CachyOS**, estás usando un sistema operativo fundamentado en **Arch Linux**. Arch tiene una forma increíblemente potente (y algo particular) de gestionar el software, dividida en dos universos paralelos:

## 🏛️ Repositorios Oficiales (Lo Seguro)

Los repositorios oficiales (se llaman `Core`, `Extra`, `Multilib`) son servidores mantenidos 24/7 por los desarrolladores oficiales de Arch Linux y del propio CachyOS.
- **La Garantía:** Todo el software que hay aquí ha sido compilado desde el código fuente original, auditado por expertos y empaquetado por el equipo oficial. Está garantizado que funciona bien y no tiene virus.
- **La Herramienta:** Para instalar de aquí se usa el gestor oficial `pacman`.
- **Ejemplo:** Firefox, VLC, Python, Git.

## 🌍 AUR (Arch User Repository) — La Biblioteca Comunitaria

El **AUR** es la joya de la corona y la razón por la que Arch Linux es tan popular.
A diferencia de los repos oficiales, el AUR **no contiene programas listos para instalar** (no tiene binarios, no tiene .exe). En su lugar, el AUR es una inmensa base de datos que contiene **"recetas"** (unos pequeños archivos de texto llamados `PKGBUILD`).

**¿Qué es una receta del AUR y cómo funciona?**
Un `PKGBUILD` es simplemente un script de instrucciones creado por un usuario cualquiera de la comunidad. Le dice literalmente a tu ordenador:
1. *"Ve a esta página web o repositorio de GitHub del creador original."*
2. *"Descarga el código fuente o el archivo .deb original."*
3. *"Compílalo (conviértelo en un programa ejecutable compatible con Arch) aquí mismo, en tu propio PC."*
4. *"Empaquétalo para que Pacman (tu gestor) sepa que está instalado."*

Gracias al AUR, CUALQUIER programa del mundo que exista para Linux (incluidos programas privativos como Spotify, Google Chrome o Microsoft Edge) se puede instalar en CachyOS, porque alguien de la comunidad ya ha creado la "receta" para descargarlo y prepararlo.

## 🤖 AUR Helpers (`yay` y `paru`)

Como buscar la receta en internet, descargarla, leerla y ejecutar los comandos de compilación a mano es muy pesado y de hackers de los 90, nacieron los **AUR Helpers** (Ayudantes del AUR). 

CachyOS incluye preinstalado `paru` (y a veces la gente prefiere `yay`, que es casi idéntico).

Estas herramientas son mágicas: automatizan todo el proceso. Ellas buscan en el AUR, leen la receta, descargan el código, lo compilan y lo instalan automáticamente. Además, `yay` y `paru` son compatibles con `pacman`, por lo que puedes usarlos para instalar *tanto software oficial como software comunitario*.

> [!warning] ⚠️ Regla de Oro CRÍTICA: NUNCA uses `sudo` con yay o paru
> - Para instalar algo oficial con pacman, usas `sudo pacman -S programa`.
> - Para instalar algo comunitario, usas **solo** `paru -S programa`.
> 
> **¿Por qué?**
> Porque compilar código de internet desde el AUR ejecutando una receta hecha por un desconocido como "Superusuario" (Administrador total) es un peligro de seguridad brutal. Si la receta de un usuario malintencionado dice *"borra todo el disco duro"*, y tú estás usando `sudo`, tu sistema obedecerá ciegamente y se romperá. 
> 
> `paru` y `yay` descargan, auditan y compilan las cosas como tu usuario normal, sin poderes destructivos. **Solo te piden la contraseña al final**, en el último segundo, cuando el paquete ya es seguro, está compilado y lo único que falta es integrarlo en el sistema de archivos del sistema operativo.
