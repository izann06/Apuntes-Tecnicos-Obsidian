# 🧩 Funciones y Manejo de Errores

## Funciones en Bash

Las funciones te permiten **agrupar comandos** bajo un nombre reutilizable. En vez de copiar y pegar el mismo bloque de código 10 veces, lo defines como función y lo llamas por su nombre.

> [!abstract] 🧰 Analogía: La Caja de Herramientas
> Si necesitas clavar un clavo, vas a la caja de herramientas y sacas el martillo. No construyes un martillo nuevo cada vez que necesitas clavar algo. Las funciones son como las herramientas de tu caja: las defines una vez y las usas cuando las necesites.

### Definición y Llamada

```bash
#!/bin/bash

# Definir una función (dos sintaxis válidas):

# Sintaxis 1 (recomendada):
saludar() {
    echo "¡Hola, bienvenido al sistema!"
    echo "Fecha: $(date)"
    echo "Usuario: $(whoami)"
}

# Sintaxis 2 (con la palabra 'function'):
function despedir {
    echo "¡Hasta luego! 👋"
}

# LLAMAR a las funciones (sin paréntesis):
saludar
echo "---"
despedir
```

> [!warning] Las funciones deben definirse ANTES de ser llamadas
> Bash lee el script de arriba a abajo. Si intentas llamar a una función antes de definirla, obtendrás un error.

### Pasar Argumentos a Funciones

Dentro de una función, los argumentos se acceden con `$1`, `$2`, `$@`, etc., **igual que en un script** → [[05.2 - Lectura de Datos y Argumentos de Script]]:

```bash
#!/bin/bash

crear_usuario() {
    local nombre=$1
    local email=$2
    
    echo "Creando usuario: $nombre"
    echo "Email: $email"
    echo "Argumentos recibidos: $#"
}

# Llamar con argumentos:
crear_usuario "Juan" "juan@email.com"
# Creando usuario: Juan
# Email: juan@email.com
# Argumentos recibidos: 2
```

### Variables Locales con `local`

Por defecto, las variables en Bash son **globales**: si defines una variable dentro de una función, es visible fuera de ella. Para evitar conflictos, usa `local`:

```bash
#!/bin/bash

mi_funcion() {
    local variable_local="Solo visible aquí dentro"
    variable_global="Visible en todo el script"
    echo "Dentro: $variable_local"
}

mi_funcion
echo "Fuera (local): $variable_local"     # (vacío, no existe fuera)
echo "Fuera (global): $variable_global"    # Visible en todo el script
```

> [!tip] Siempre usa `local` dentro de funciones
> Es una buena práctica declarar todas las variables de una función como `local`. Esto evita que una función modifique accidentalmente una variable que otra parte del script está usando.

### Retornar Valores

Las funciones en Bash **no retornan valores** como en otros lenguajes. Usan `return` para devolver un **código de salida** (número entre 0 y 255) o `echo` para devolver texto:

```bash
#!/bin/bash

# Método 1: return (solo números 0-255, código de estado)
es_par() {
    if [ $(( $1 % 2 )) -eq 0 ]; then
        return 0    # Éxito = es par
    else
        return 1    # Error = no es par
    fi
}

es_par 4
if [ $? -eq 0 ]; then
    echo "4 es par"
fi

# Método 2: echo (para devolver texto o valores)
obtener_ip() {
    local ip=$(hostname -I | awk '{print $1}')
    echo "$ip"    # "Retorna" el texto
}

MI_IP=$(obtener_ip)    # Capturar la salida con $()
echo "Tu IP es: $MI_IP"
```

## Manejo de Errores

### Códigos de Salida (`$?`)

Cada comando en Linux produce un **código de salida** (exit code) al terminar:

| Código | Significado |
|--------|-------------|
| `0` | **Éxito** — El comando se ejecutó correctamente |
| `1` | **Error general** — Algo falló |
| `2` | **Error de uso** — Argumentos incorrectos |
| `126` | Permiso denegado (no se puede ejecutar) |
| `127` | Comando no encontrado |
| `128+N` | Proceso terminado por la señal N |
| `130` | Terminado con `Ctrl+C` (128 + 2 = SIGINT) |

```bash
# Ver el código de salida del último comando:
ls /etc/passwd
echo $?    # 0 (éxito, el archivo existe)

ls /archivo_inexistente
echo $?    # 2 (error, no se encontró)

grep "patron" archivo.txt
echo $?    # 0 si encontró coincidencias, 1 si no encontró

# Usar $? en scripts:
cp archivo_importante.txt /backup/
if [ $? -eq 0 ]; then
    echo "✅ Copia exitosa"
else
    echo "❌ Error al copiar"
fi
```

### `exit` — Terminar el Script

```bash
#!/bin/bash

# Verificar que se ejecuta como root:
if [ "$(whoami)" != "root" ]; then
    echo "❌ Este script debe ejecutarse como root"
    exit 1    # Salir con código de error
fi

# Si llegamos aquí, somos root:
echo "✅ Ejecutando como root..."

# ... hacer cosas ...

exit 0    # Salir con éxito
```

### Combinación Lógica: `&&` y `||`

Estos operadores permiten **encadenar comandos** basándose en el éxito o fracaso del anterior:

```bash
# && (AND): Ejecuta el segundo solo SI el primero tuvo ÉXITO:
mkdir /backup && echo "Directorio creado"
# Si mkdir falla, echo NO se ejecuta

# || (OR): Ejecuta el segundo solo SI el primero FALLÓ:
mkdir /backup || echo "Error al crear directorio"
# Si mkdir tiene éxito, echo NO se ejecuta

# Combinar ambos (patrón común):
ping -c 1 google.com && echo "✅ Online" || echo "❌ Offline"

# Caso real: Compilar y ejecutar solo si la compilación tiene éxito:
gcc programa.c -o programa && ./programa || echo "Error de compilación"

# Caso real: Actualizar sistema (ejecutar upgrade solo si update tiene éxito):
sudo apt update && sudo apt upgrade -y || echo "Error en la actualización"
```

### Ejemplo Completo: Script Robusto con Funciones y Errores

```bash
#!/bin/bash
# ============================================
# Script: backup_seguro.sh
# Descripción: Backup con validaciones y manejo de errores
# ============================================

# ── Funciones ──

log() {
    local nivel=$1
    local mensaje=$2
    echo "$(date '+%H:%M:%S') [$nivel] $mensaje"
}

verificar_directorio() {
    local dir=$1
    if [ ! -d "$dir" ]; then
        log "ERROR" "El directorio $dir no existe"
        return 1
    fi
    if [ ! -r "$dir" ]; then
        log "ERROR" "Sin permisos de lectura en $dir"
        return 1
    fi
    return 0
}

crear_backup() {
    local origen=$1
    local destino=$2
    local nombre="backup_$(date +%Y%m%d_%H%M%S).tar.gz"
    
    log "INFO" "Creando backup: $nombre"
    tar -czf "$destino/$nombre" "$origen" 2>/dev/null
    
    if [ $? -eq 0 ]; then
        local tamaño=$(du -h "$destino/$nombre" | cut -f1)
        log "OK" "Backup creado: $destino/$nombre ($tamaño)"
        return 0
    else
        log "ERROR" "Falló la creación del backup"
        return 1
    fi
}

# ── Programa Principal ──

# Validar argumentos:
if [ $# -ne 2 ]; then
    echo "Uso: $0 <directorio_origen> <directorio_destino>"
    exit 1
fi

ORIGEN=$1
DESTINO=$2

log "INFO" "Iniciando proceso de backup"

# Verificar directorios:
verificar_directorio "$ORIGEN" || exit 1
verificar_directorio "$DESTINO" || { 
    log "INFO" "Creando directorio destino..."
    mkdir -p "$DESTINO" || exit 1
}

# Crear backup:
crear_backup "$ORIGEN" "$DESTINO" && \
    log "INFO" "Proceso completado exitosamente" || \
    log "ERROR" "El proceso falló"
```
