# 🧮 Operaciones Aritméticas y Estructuras Condicionales

## Aritmética en Bash

Bash puede hacer operaciones matemáticas básicas de varias formas:

### Doble Paréntesis `(( ))`

```bash
#!/bin/bash

# Operaciones básicas con (( )):
a=10
b=3

((suma = a + b))        # 13
((resta = a - b))        # 7
((multiplicacion = a * b))  # 30
((division = a / b))     # 3 (división entera, sin decimales)
((modulo = a % b))       # 1 (resto de la división)
((potencia = a ** 2))    # 100 (10 al cuadrado)

echo "Suma: $suma"
echo "Resta: $resta"
echo "Multiplicación: $multiplicacion"
echo "División: $division"
echo "Módulo: $modulo"
echo "Potencia: $potencia"

# Incremento y decremento:
((a++))     # a = 11 (incrementar en 1)
((a--))     # a = 10 (decrementar en 1)
((a += 5))  # a = 15 (sumar 5)
((a -= 3))  # a = 12 (restar 3)
((a *= 2))  # a = 24 (multiplicar por 2)
```

### Comando `let`

```bash
let "resultado = 10 + 5"
echo $resultado    # 15

let "x = 100 / 3"
echo $x            # 33

let "contador++"
```

### Expansión Aritmética `$(( ))`

```bash
# Usar el resultado directamente dentro de un echo:
echo "10 + 5 = $((10 + 5))"    # 10 + 5 = 15
echo "3 * 7 = $((3 * 7))"      # 3 * 7 = 21

# Guardar en variable:
resultado=$((100 - 35))
echo $resultado    # 65
```

> [!warning] Bash solo hace aritmética con ENTEROS
> Bash no soporta números decimales. `10 / 3` da `3`, no `3.333...`. Si necesitas decimales, usa `bc`:
> ```bash
> echo "scale=2; 10 / 3" | bc
> # 3.33
> ```

## Estructuras Condicionales: `if / elif / else / fi`

### Sintaxis Básica

```bash
if [ condición ]; then
    # Código si la condición es verdadera
elif [ otra_condición ]; then
    # Código si la segunda condición es verdadera
else
    # Código si ninguna condición fue verdadera
fi
```

> [!danger] ⚠️ Los espacios son OBLIGATORIOS
> ```bash
> # ❌ INCORRECTO (sin espacios dentro de los corchetes):
> if [$variable = "valor"]; then
> 
> # ✅ CORRECTO (con espacios):
> if [ $variable = "valor" ]; then
> ```
> Los corchetes `[` y `]` son en realidad un **comando** (`test`), y los espacios son necesarios para separar los argumentos.

### Ejemplo Básico

```bash
#!/bin/bash

read -p "¿Cuántos años tienes? " edad

if [ $edad -ge 18 ]; then
    echo "✅ Eres mayor de edad"
elif [ $edad -ge 13 ]; then
    echo "🟡 Eres adolescente"
else
    echo "❌ Eres menor de edad"
fi
```

## Operadores de Comparación

### Comparación Numérica

| Operador | Significado | Ejemplo |
|----------|-------------|---------|
| `-eq` | **Equal** (igual) | `[ $a -eq $b ]` |
| `-ne` | **Not equal** (distinto) | `[ $a -ne $b ]` |
| `-gt` | **Greater than** (mayor que) | `[ $a -gt $b ]` |
| `-lt` | **Less than** (menor que) | `[ $a -lt $b ]` |
| `-ge` | **Greater or equal** (mayor o igual) | `[ $a -ge $b ]` |
| `-le` | **Less or equal** (menor o igual) | `[ $a -le $b ]` |

```bash
#!/bin/bash
nota=75

if [ $nota -ge 90 ]; then
    echo "Sobresaliente"
elif [ $nota -ge 70 ]; then
    echo "Notable"
elif [ $nota -ge 50 ]; then
    echo "Aprobado"
else
    echo "Suspenso"
fi
```

### Comparación de Cadenas de Texto

| Operador | Significado | Ejemplo |
|----------|-------------|---------|
| `=` | Igual | `[ "$a" = "$b" ]` |
| `!=` | Distinto | `[ "$a" != "$b" ]` |
| `-z` | Cadena vacía (zero length) | `[ -z "$a" ]` |
| `-n` | Cadena NO vacía (non-zero) | `[ -n "$a" ]` |

```bash
#!/bin/bash
read -p "¿Cuál es tu sistema operativo? " so

if [ "$so" = "Linux" ]; then
    echo "¡Excelente elección! 🐧"
elif [ "$so" = "Windows" ]; then
    echo "Está bien, pero prueba Linux 😉"
elif [ -z "$so" ]; then
    echo "No escribiste nada"
else
    echo "No conozco ese sistema: $so"
fi
```

> [!tip] Siempre usa comillas dobles con variables de cadena
> ```bash
> # ❌ Si la variable está vacía, esto da error de sintaxis:
> if [ $nombre = "Juan" ]; then
> # bash: [: =: unary operator expected
> 
> # ✅ Con comillas dobles, funciona siempre:
> if [ "$nombre" = "Juan" ]; then
> ```

### Verificación de Archivos

| Operador | Significado | Ejemplo |
|----------|-------------|---------|
| `-e` | Existe (el archivo o directorio existe) | `[ -e "/etc/passwd" ]` |
| `-f` | Es un archivo regular | `[ -f "notas.txt" ]` |
| `-d` | Es un directorio | `[ -d "/home/juan" ]` |
| `-r` | Tiene permiso de lectura | `[ -r "config.txt" ]` |
| `-w` | Tiene permiso de escritura | `[ -w "datos.txt" ]` |
| `-x` | Tiene permiso de ejecución | `[ -x "script.sh" ]` |
| `-s` | Existe y tiene tamaño > 0 | `[ -s "datos.txt" ]` |

```bash
#!/bin/bash
ARCHIVO="/etc/passwd"

if [ -e "$ARCHIVO" ]; then
    echo "El archivo existe"
    
    if [ -r "$ARCHIVO" ]; then
        echo "Puedes leerlo"
        echo "Tiene $(wc -l < "$ARCHIVO") líneas"
    else
        echo "No tienes permiso de lectura"
    fi
else
    echo "El archivo no existe"
fi
```

## Operadores Lógicos: AND y OR

```bash
# AND (&&): Ambas condiciones deben ser verdaderas
if [ $edad -ge 18 ] && [ $edad -le 65 ]; then
    echo "Estás en edad laboral"
fi

# OR (||): Al menos una condición debe ser verdadera
if [ "$respuesta" = "s" ] || [ "$respuesta" = "S" ]; then
    echo "Has respondido sí"
fi

# Combinar AND y OR:
if [ -f "$archivo" ] && [ -r "$archivo" ]; then
    echo "El archivo existe y puedes leerlo"
fi

# Negación con !
if [ ! -e "$archivo" ]; then
    echo "El archivo NO existe"
fi
```

## Sentencia `case`: Menús Eficientes

La sentencia `case` es perfecta para cuando necesitas comparar una variable con **múltiples valores posibles**. Es más limpia que encadenar muchos `elif`.

```bash
#!/bin/bash

echo "========================="
echo "   MENÚ PRINCIPAL"
echo "========================="
echo "1) Ver información del sistema"
echo "2) Ver uso de disco"
echo "3) Ver usuarios conectados"
echo "4) Ver procesos activos"
echo "5) Salir"
echo "========================="
read -p "Elige una opción: " opcion

case $opcion in
    1)
        echo "--- Información del Sistema ---"
        uname -a
        ;;
    2)
        echo "--- Uso de Disco ---"
        df -h
        ;;
    3)
        echo "--- Usuarios Conectados ---"
        who
        ;;
    4)
        echo "--- Top 10 Procesos por CPU ---"
        ps aux --sort=-%cpu | head -11
        ;;
    5)
        echo "¡Hasta luego! 👋"
        exit 0
        ;;
    *)
        echo "❌ Opción no válida: $opcion"
        echo "Por favor, elige un número del 1 al 5"
        ;;
esac
```

### Sintaxis de `case`

```bash
case $variable in
    patron1)
        # Código para patrón 1
        ;;            # ;; = break (fin del caso)
    patron2 | patron3)
        # Código para patrón 2 O 3 (múltiples patrones)
        ;;
    *)
        # Código por defecto (si nada coincide)
        # Similar al "default" de otros lenguajes
        ;;
esac              # "case" al revés = fin de la estructura
```

```bash
#!/bin/bash
# Ejemplo: Detectar el tipo de archivo por extensión

archivo=$1
extension="${archivo##*.}"    # Extraer la extensión

case $extension in
    txt | md | log)
        echo "📄 Archivo de texto"
        ;;
    jpg | jpeg | png | gif)
        echo "🖼️ Archivo de imagen"
        ;;
    mp3 | wav | flac)
        echo "🎵 Archivo de audio"
        ;;
    mp4 | avi | mkv)
        echo "🎬 Archivo de video"
        ;;
    sh)
        echo "📜 Script de Bash"
        ;;
    py)
        echo "🐍 Script de Python"
        ;;
    *)
        echo "❓ Tipo desconocido: .$extension"
        ;;
esac
```
