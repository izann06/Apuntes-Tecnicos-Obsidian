# ⏰ Programación de Tareas con Cron (Crontab)

## ¿Qué es Cron?

**Cron** es un **demonio** (servicio que corre en segundo plano) que ejecuta comandos o scripts de forma **automática y programada** en fechas y horarios específicos. Es el equivalente a programar una alarma en tu teléfono, pero para ejecutar comandos de Linux.

> [!abstract] ⏰ Analogía: El Despertador Programable
> Imagina un despertador que no solo te despierta a las 7 AM, sino que también puede:
> - Encender la cafetera a las 6:55 AM cada día
> - Regar las plantas todos los lunes y jueves a las 8 PM
> - Hacer una copia de seguridad de tus fotos cada domingo a las 3 AM
> - Revisar la temperatura del servidor cada 5 minutos
> 
> Eso es Cron: un sistema de alarmas que ejecuta tareas automáticamente.

## La Sintaxis Cron: Los 5 Campos de Asteriscos

Cada línea en el crontab tiene esta estructura:

```
*  *  *  *  *  comando_a_ejecutar
│  │  │  │  │
│  │  │  │  └── Día de la semana (0-7, 0 y 7 = domingo)
│  │  │  └── Mes (1-12)
│  │  └── Día del mes (1-31)
│  └── Hora (0-23)
└── Minuto (0-59)
```

### Tabla de los 5 Campos

| Campo | Rango | Valores Especiales |
|-------|-------|-------------------|
| **Minuto** | 0-59 | `*` = cada minuto |
| **Hora** | 0-23 | `0` = medianoche, `12` = mediodía |
| **Día del mes** | 1-31 | `1` = primer día del mes |
| **Mes** | 1-12 | `1` = enero, `12` = diciembre |
| **Día de la semana** | 0-7 | `0` y `7` = domingo, `1` = lunes |

### Caracteres Especiales

| Carácter | Significado | Ejemplo |
|----------|-------------|---------|
| `*` | **Cualquier valor** (todos) | `* * * * *` = cada minuto |
| `,` | **Lista** de valores | `1,15,30` = en el minuto 1, 15 y 30 |
| `-` | **Rango** de valores | `1-5` = de lunes a viernes |
| `/` | **Cada N** (intervalo) | `*/5` = cada 5 (minutos/horas/etc.) |

## Ejemplos de Programación

### Ejemplos Básicos

```bash
# Cada minuto (para testing, ¡no usar en producción!):
* * * * * /ruta/al/script.sh

# Cada hora (al minuto 0):
0 * * * * /ruta/al/script.sh

# Cada día a las 2:30 AM:
30 2 * * * /ruta/al/script.sh

# Cada lunes a las 9:00 AM:
0 9 * * 1 /ruta/al/script.sh

# Cada 5 minutos:
*/5 * * * * /ruta/al/script.sh

# Cada 15 minutos:
*/15 * * * * /ruta/al/script.sh

# De lunes a viernes a las 8:00 AM:
0 8 * * 1-5 /ruta/al/script.sh
```

### Ejemplos Avanzados

```bash
# El primer día de cada mes a medianoche:
0 0 1 * * /ruta/backup_mensual.sh

# Cada domingo a las 3:00 AM:
0 3 * * 0 /ruta/mantenimiento_semanal.sh

# A las 8 AM y 6 PM de lunes a viernes:
0 8,18 * * 1-5 /ruta/reporte.sh

# Cada 30 minutos durante el horario laboral (8-18h):
*/30 8-18 * * 1-5 /ruta/monitoreo.sh

# Los días 1 y 15 de cada mes a las 10 AM:
0 10 1,15 * * /ruta/facturacion.sh

# Cada hora entre las 8 AM y las 5 PM:
0 8-17 * * * /ruta/check_servicios.sh
```

### Tabla de Ejemplos Rápidos

| Programación | Expresión Cron | Cuándo se ejecuta |
|-------------|----------------|-------------------|
| Cada minuto | `* * * * *` | Cada 60 segundos |
| Cada 5 minutos | `*/5 * * * *` | :00, :05, :10, :15... |
| Cada hora | `0 * * * *` | Cada hora en punto |
| Diario a las 2:30 AM | `30 2 * * *` | Todos los días a las 2:30 |
| Lunes a viernes 9 AM | `0 9 * * 1-5` | Días laborables a las 9:00 |
| Cada domingo 3 AM | `0 3 * * 0` | Domingos a las 3:00 |
| 1º de cada mes | `0 0 1 * *` | Día 1 a medianoche |
| Cada 6 horas | `0 */6 * * *` | 00:00, 06:00, 12:00, 18:00 |

## Comandos de Control de Crontab

```bash
# EDITAR tu crontab personal:
crontab -e
# Se abre en tu editor de texto (nano, vim, etc.)
# Añade las líneas de cron, guarda y sal

# LISTAR las tareas programadas:
crontab -l
# Muestra todas tus tareas actuales

# ELIMINAR todas las tareas programadas:
crontab -r
# ¡CUIDADO! Borra TODAS tus tareas sin preguntar

# Eliminar con confirmación:
crontab -ri
# ¿Seguro que quieres borrar el crontab? (y/n)

# Ver el crontab de OTRO usuario (como root):
sudo crontab -u maria -l

# Editar el crontab de otro usuario:
sudo crontab -u maria -e
```

## Buenas Prácticas con Cron

### 1. Usa Rutas Absolutas SIEMPRE

```bash
# ❌ INCORRECTO (ruta relativa):
*/5 * * * * ./backup.sh

# ✅ CORRECTO (ruta absoluta):
*/5 * * * * /home/juan/scripts/backup.sh
```

Cron no usa tu PATH ni tu directorio de trabajo → [[01.3 - Rutas Absolutas vs Relativas]]

### 2. Redirige la Salida a un Log

```bash
# Sin redirección: Cron envía la salida por email (puede saturar)
# Con redirección: La salida va a un archivo de log

# Guardar salida Y errores:
30 2 * * * /home/juan/scripts/backup.sh >> /var/log/backup.log 2>&1

# Descartar toda la salida (modo silencioso):
*/5 * * * * /home/juan/scripts/check.sh > /dev/null 2>&1
```

### 3. Establece la UMask y Variables

```bash
# En el crontab puedes definir variables de entorno:
SHELL=/bin/bash
PATH=/usr/local/bin:/usr/bin:/bin
MAILTO=admin@ejemplo.com

# Las tareas:
30 2 * * * /home/juan/scripts/backup.sh >> /var/log/backup.log 2>&1
```

### Ejemplo Completo de Crontab

```bash
# Editar: crontab -e

# ── Variables de entorno ──
SHELL=/bin/bash
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
MAILTO=""

# ── Tareas programadas ──

# Backup diario a las 2:30 AM
30 2 * * * /home/juan/scripts/backup_diario.sh >> /var/log/cron_backup.log 2>&1

# Verificar servicios cada 5 minutos
*/5 * * * * /home/juan/scripts/check_servicios.sh > /dev/null 2>&1

# Limpiar archivos temporales cada domingo a las 4 AM
0 4 * * 0 /home/juan/scripts/limpieza.sh >> /var/log/cron_limpieza.log 2>&1

# Actualizar el sistema cada lunes a las 3 AM
0 3 * * 1 /usr/bin/apt update && /usr/bin/apt upgrade -y >> /var/log/cron_update.log 2>&1

# Reporte de disco el primer día de cada mes
0 8 1 * * /home/juan/scripts/reporte_disco.sh >> /var/log/cron_disco.log 2>&1
```
