# 📥 Lectura de Datos y Argumentos de Script

## Lectura Interactiva con `read`

El comando `read` permite que tu script **solicite información al usuario** durante la ejecución, como si fuera un formulario interactivo.

```bash
#!/bin/bash

# Uso básico de read:
echo "¿Cómo te llamas?"
read nombre
echo "¡Hola, $nombre!"

# read con prompt integrado (-p):
read -p "¿Cuál es tu edad? " edad
echo "Tienes $edad años"

# read para contraseñas (-s = silent, no muestra lo que escribes):
read -s -p "Introduce tu contraseña: " password
echo ""    # Salto de línea después del input oculto
echo "Contraseña recibida (no la mostraré por seguridad)"

# read con tiempo límite (-t = timeout en segundos):
read -t 10 -p "Tienes 10 segundos para responder: " respuesta

# read con límite de caracteres (-n):
read -n 1 -p "¿Continuar? (s/n): " opcion
echo ""
if [ "$opcion" = "s" ]; then
    echo "Continuando..."
fi

# Leer múltiples valores en una sola línea:
read -p "Introduce nombre y apellido: " nombre apellido
echo "Nombre: $nombre"
echo "Apellido: $apellido"
```

### Opciones de `read`

| Opción | Descripción | Ejemplo |
|--------|-------------|---------|
| `-p "texto"` | Muestra un prompt antes de leer | `read -p "Nombre: " var` |
| `-s` | Silencioso (no muestra lo que se escribe) | `read -s -p "Password: " pass` |
| `-t N` | Timeout de N segundos | `read -t 5 -p "Rápido: " var` |
| `-n N` | Lee máximo N caracteres | `read -n 1 -p "s/n: " var` |
| `-r` | No interpretar backslashes | `read -r linea` |

### Ejemplo Práctico: Script de Registro

```bash
#!/bin/bash

echo "============================="
echo "  FORMULARIO DE REGISTRO"
echo "============================="

read -p "👤 Nombre completo: " nombre
read -p "📧 Email: " email
read -p "🎂 Edad: " edad
read -s -p "🔑 Contraseña: " password
echo ""
read -s -p "🔑 Confirmar contraseña: " password2
echo ""

if [ "$password" = "$password2" ]; then
    echo ""
    echo "✅ Registro exitoso:"
    echo "   Nombre: $nombre"
    echo "   Email: $email"
    echo "   Edad: $edad"
else
    echo ""
    echo "❌ Error: Las contraseñas no coinciden"
fi
```

## Argumentos de Script (Parámetros Posicionales)

En vez de pedirle datos al usuario durante la ejecución, puedes pasar los datos **directamente al lanzar el script** como argumentos en la línea de comandos:

```bash
./mi_script.sh argumento1 argumento2 argumento3
```

### Variables Especiales de Argumentos

| Variable | Contenido | Ejemplo |
|----------|-----------|---------|
| `$0` | Nombre del script | `./mi_script.sh` |
| `$1` | Primer argumento | `argumento1` |
| `$2` | Segundo argumento | `argumento2` |
| `$3` a `$9` | Argumentos 3 al 9 | `argumento3` ... |
| `${10}` | Argumento 10+ (necesita llaves) | `argumento10` |
| `$#` | **Cantidad** total de argumentos | `3` |
| `$@` | **Todos** los argumentos (como lista) | `argumento1 argumento2 argumento3` |
| `$*` | Todos los argumentos (como una sola cadena) | `"argumento1 argumento2 argumento3"` |

### Ejemplo Básico

```bash
#!/bin/bash
# Archivo: saludo.sh

echo "Nombre del script: $0"
echo "Primer argumento: $1"
echo "Segundo argumento: $2"
echo "Número de argumentos: $#"
echo "Todos los argumentos: $@"
```

```bash
# Ejecutar:
./saludo.sh Juan 25
# Nombre del script: ./saludo.sh
# Primer argumento: Juan
# Segundo argumento: 25
# Número de argumentos: 2
# Todos los argumentos: Juan 25
```

### Ejemplo Práctico: Script de Backup

```bash
#!/bin/bash
# Archivo: backup.sh
# Uso: ./backup.sh /ruta/origen /ruta/destino

# Validar que se pasaron los argumentos necesarios:
if [ $# -ne 2 ]; then
    echo "❌ Error: Se necesitan exactamente 2 argumentos"
    echo "Uso: $0 <directorio_origen> <directorio_destino>"
    exit 1
fi

ORIGEN=$1
DESTINO=$2
FECHA=$(date +%Y%m%d_%H%M%S)
ARCHIVO_BACKUP="backup_${FECHA}.tar.gz"

echo "📦 Creando backup..."
echo "   Origen:  $ORIGEN"
echo "   Destino: $DESTINO/$ARCHIVO_BACKUP"

tar -czf "$DESTINO/$ARCHIVO_BACKUP" "$ORIGEN"

if [ $? -eq 0 ]; then
    echo "✅ Backup creado exitosamente"
    echo "   Tamaño: $(du -h "$DESTINO/$ARCHIVO_BACKUP" | cut -f1)"
else
    echo "❌ Error al crear el backup"
    exit 1
fi
```

```bash
# Ejecutar:
./backup.sh /home/juan/proyectos /home/juan/backups
# 📦 Creando backup...
#    Origen:  /home/juan/proyectos
#    Destino: /home/juan/backups/backup_20260901_103045.tar.gz
# ✅ Backup creado exitosamente
#    Tamaño: 15M
```

### Iterar Sobre Todos los Argumentos

```bash
#!/bin/bash
# Archivo: procesar_archivos.sh
# Uso: ./procesar_archivos.sh archivo1.txt archivo2.txt archivo3.txt

echo "Procesando $# archivos..."

for archivo in "$@"; do
    if [ -f "$archivo" ]; then
        lineas=$(wc -l < "$archivo")
        echo "  ✅ $archivo → $lineas líneas"
    else
        echo "  ❌ $archivo → No existe"
    fi
done

echo "Procesamiento completado"
```

```bash
./procesar_archivos.sh notas.txt config.json datos.csv inexistente.txt
# Procesando 4 archivos...
#   ✅ notas.txt → 45 líneas
#   ✅ config.json → 12 líneas
#   ✅ datos.csv → 1000 líneas
#   ❌ inexistente.txt → No existe
# Procesamiento completado
```

### `read` vs Argumentos: ¿Cuándo Usar Cada Uno?

| Aspecto | `read` (interactivo) | Argumentos `$1, $2...` |
|---------|---------------------|----------------------|
| **Cuándo usarlo** | Scripts interactivos con menús | Scripts automatizados y de una línea |
| **Automatizable** | ❌ Difícil (requiere interacción humana) | ✅ Totalmente automatizable |
| **Uso con Cron** | ❌ No funciona | ✅ Perfecto → [[05.6 - Programación de Tareas con Cron (Crontab)]] |
| **Experiencia** | Más amigable para el usuario | Más eficiente para el administrador |
| **Ejemplo** | `read -p "Nombre: " nombre` | `./script.sh "Juan"` |
