# 🃏 Comodines (Wildcards) e Historial de Comandos

## Comodines (Wildcards / Globbing)

Los **comodines** (wildcards) son caracteres especiales que representan uno o más caracteres en los nombres de archivos. Te permiten seleccionar múltiples archivos de golpe sin tener que escribir cada nombre individualmente. Este proceso se llama **globbing** (expansión de patrones).

> [!abstract] 🃏 Analogía: Las Cartas Comodín del Póker
> En los juegos de cartas, un **comodín** puede sustituir a cualquier otra carta. En Linux, los comodines funcionan igual: sustituyen caracteres en los nombres de archivos. El asterisco `*` es como un "súper comodín" que puede representar cualquier cosa, mientras que `?` es un comodín más limitado que solo sustituye una carta (un carácter).

---

### El Asterisco `*` — Cero o Más Caracteres

El asterisco `*` reemplaza **cualquier cantidad de caracteres** (incluyendo ninguno). Es el comodín más usado.

```bash
# Supongamos este directorio:
ls
# datos.csv  foto.jpg  foto2.jpg  informe.pdf  notas.txt  script.sh  test.txt

# Todos los archivos .txt:
ls *.txt
# notas.txt  test.txt

# Todos los archivos que empiezan con "foto":
ls foto*
# foto.jpg  foto2.jpg

# Todos los archivos que contienen "o" en su nombre:
ls *o*
# foto.jpg  foto2.jpg  informe.pdf  notas.txt

# Todos los archivos (equivalente a ls sin argumentos):
ls *

# Copiar todos los .jpg a otra carpeta:
cp *.jpg /home/juan/fotos/

# Borrar todos los archivos .log (cuidado):
rm *.log

# Mover todos los scripts a una carpeta:
mv *.sh scripts/
```

---

### El Signo de Interrogación `?` — Exactamente Un Carácter

El signo `?` reemplaza **exactamente un carácter** (ni más, ni menos). Es más preciso que `*`.

```bash
# Supongamos:
ls
# foto1.jpg  foto2.jpg  foto3.jpg  foto10.jpg  foto.jpg

# Archivos que son "foto" + UN solo carácter + ".jpg":
ls foto?.jpg
# foto1.jpg  foto2.jpg  foto3.jpg
# (foto10.jpg NO coincide porque "10" son DOS caracteres)
# (foto.jpg NO coincide porque no tiene ningún carácter extra)

# Archivos con exactamente 4 letras + .txt:
ls ????.txt
# test.txt
# (notas.txt NO coincide: "notas" tiene 5 letras)

# Combinar múltiples ?:
ls foto??.jpg
# foto10.jpg  (dos caracteres después de "foto")
```

---

### Los Corchetes `[]` — Rangos Específicos

Los corchetes `[]` permiten especificar un **conjunto o rango de caracteres** en una posición determinada.

```bash
# Archivos que empiezan con a, b o c:
ls [abc]*
# archivo.txt  backup.zip  config.json

# Archivos que empiezan con una letra de la A a la M (rango):
ls [A-M]*
# Documentos  Escritorio  Imágenes

# Archivos que empiezan con una letra minúscula:
ls [a-z]*

# Archivos que empiezan con un dígito:
ls [0-9]*
# 01_intro.md  02_setup.md  03_config.md

# NEGAR un rango con ! o ^  (archivos que NO empiezan con vocal):
ls [!aeiou]*
# script.sh  backup.zip  config.json  datos.csv

# Combinar con otros comodines:
ls foto[1-3].jpg
# foto1.jpg  foto2.jpg  foto3.jpg

ls [A-Z]*.txt
# Archivo.txt  Borrador.txt  (solo los que empiezan con mayúscula)
```

---

### Tabla Comparativa de Comodines

| Comodín | Representa | Ejemplo | Coincide con | NO coincide con |
|---------|-----------|---------|-------------|-----------------|
| `*` | Cero o más caracteres | `*.txt` | `notas.txt`, `a.txt`, `.txt` | `notas.pdf` |
| `?` | Exactamente un carácter | `foto?.jpg` | `foto1.jpg`, `fotoA.jpg` | `foto10.jpg`, `foto.jpg` |
| `[abc]` | Uno de los caracteres listados | `[abc]*.txt` | `archivo.txt`, `backup.txt` | `datos.txt` |
| `[a-z]` | Un carácter en el rango | `[a-z]*` | `script.sh`, `notas.txt` | `Archivo.txt`, `1data.csv` |
| `[!abc]` | Cualquiera EXCEPTO los listados | `[!0-9]*` | `script.sh` | `01_intro.md` |

### Ejemplos Prácticos del Día a Día

```bash
# Listar solo imágenes (jpg, png, gif):
ls *.{jpg,png,gif}

# Copiar todos los archivos de configuración a un backup:
cp /etc/*.conf /backup/configs/

# Borrar archivos temporales con diferentes extensiones:
rm *.tmp *.bak *.swp

# Contar cuántos archivos .log hay:
ls *.log | wc -l

# Buscar scripts de Bash ejecutables:
ls -la *.sh
```

## El Historial de Comandos: Tu Memoria Extendida

Linux guarda un registro de **todos los comandos que escribes** en un archivo llamado `~/.bash_history` (o `~/.zsh_history` si usas ZSH → [[06.2 - Transición a ZSH y Oh My ZSH]]). Esto te permite buscar, repetir y reutilizar comandos anteriores sin tener que escribirlos de nuevo.

### `history` — Ver el Historial Completo

```bash
# Ver todo el historial:
history
#     1  pwd
#     2  cd /etc
#     3  ls -la
#     4  cat passwd
#     5  cd ~
#     6  mkdir proyectos
#  ...
#  1023  sudo apt update
#  1024  history

# Ver solo los últimos N comandos:
history 10
# Muestra los últimos 10 comandos

# Buscar en el historial con grep:
history | grep "apt install"
#   45  sudo apt install tree
#  123  sudo apt install htop
#  456  sudo apt install curl

# Ver cuántos comandos hay en el historial:
history | wc -l
# 1024
```

### Navegar el Historial con el Teclado

| Atajo | Acción |
|-------|--------|
| `↑` (flecha arriba) | Comando anterior |
| `↓` (flecha abajo) | Comando siguiente |
| `Ctrl + R` | **Búsqueda inversa**: escribes parte del comando y lo encuentra |
| `Ctrl + G` | Cancelar la búsqueda con `Ctrl+R` |

```bash
# Ctrl + R es MUY poderoso:
# Presiona Ctrl+R, luego escribe "install"
# (reverse-i-search)`install': sudo apt install htop
# Presiona Enter para ejecutarlo, o Ctrl+R de nuevo para buscar el anterior
```

> [!tip] `Ctrl + R` es tu mejor amigo
> En vez de escribir `history | grep "algo"`, simplemente presiona `Ctrl + R` y empieza a escribir. Linux buscará en tu historial el último comando que contenga esas letras. Es **infinitamente más rápido** y lo usarás constantemente.

### Expansión del Historial: Repetir Comandos Rápidamente

Linux tiene atajos especiales para repetir comandos del historial sin tener que buscarlos:

```bash
# !! — Repetir el ÚLTIMO comando ejecutado:
sudo apt update
# Oops, olvidé usar sudo:
apt install htop
# E: Could not open lock file - Permission denied
sudo !!
# Se ejecuta: sudo apt install htop  ← ¡Genial!

# !n — Ejecutar el comando número N del historial:
history
#    45  sudo apt install tree
#   123  ls -la /var/log
!45
# Se ejecuta: sudo apt install tree

# !comando — Ejecutar el ÚLTIMO comando que empiece con esa palabra:
!sudo
# Se ejecuta el último comando que empezó con "sudo"

!ls
# Se ejecuta el último comando que empezó con "ls"

# !$ — Reutilizar el ÚLTIMO argumento del comando anterior:
mkdir /home/juan/nuevo_proyecto
cd !$
# Se ejecuta: cd /home/juan/nuevo_proyecto
```

### Tabla de Expansiones del Historial

| Expansión | Significado | Ejemplo |
|-----------|-----------|---------|
| `!!` | Último comando completo | `sudo !!` → ejecuta el anterior con sudo |
| `!n` | Comando número N | `!45` → ejecuta el comando #45 |
| `!-n` | N comandos atrás | `!-3` → el de hace 3 comandos |
| `!texto` | Último que empieza con "texto" | `!sudo` → el último sudo que usaste |
| `!$` | Último argumento del anterior | `cd !$` → va al último argumento |
| `!*` | Todos los argumentos del anterior | `echo !*` → muestra todos los args |

---

### Borrar y Controlar el Historial

```bash
# Borrar TODO el historial:
history -c

# Borrar una línea específica del historial:
history -d 45     # Borra la entrada número 45

# Ver dónde se guarda el historial:
echo $HISTFILE
# /home/juan/.bash_history

# Ver cuántos comandos se guardan (por defecto ~1000-2000):
echo $HISTSIZE
# 1000

# Cambiar el tamaño del historial (añadir a ~/.bashrc):
export HISTSIZE=10000
export HISTFILESIZE=20000
```

### El Truco Hacker: Omitir Comandos del Historial

> [!tip] 🕵️ El Truco del Espacio Inicial
> Si escribes un comando empezando con un **espacio en blanco** antes del comando, ese comando **NO se guardará** en el historial. Esto es útil cuando escribes contraseñas o comandos sensibles que no quieres que queden registrados:
> 
> ```bash
> # Este comando SÍ se guarda en el historial:
> mysql -u root -p mi_contraseña_secreta
> 
> # Este comando NO se guarda (fíjate en el espacio al inicio):
>  mysql -u root -p mi_contraseña_secreta
> # ↑ Espacio antes del comando
> ```
> 
> Este comportamiento depende de la variable `HISTCONTROL`. Para asegurarte de que funciona, añade esto a tu `~/.bashrc`:
> ```bash
> export HISTCONTROL=ignoreboth
> # "ignoreboth" = ignorar duplicados + ignorar los que empiezan con espacio
> ```

### Otros Atajos de Teclado Esenciales en la Terminal

| Atajo | Acción |
|-------|--------|
| `Ctrl + A` | Ir al **inicio** de la línea |
| `Ctrl + E` | Ir al **final** de la línea |
| `Ctrl + U` | Borrar todo **antes** del cursor |
| `Ctrl + K` | Borrar todo **después** del cursor |
| `Ctrl + W` | Borrar la **palabra anterior** |
| `Ctrl + L` | **Limpiar** la pantalla (equivalente a `clear`) |
| `Ctrl + C` | **Cancelar** el comando actual |
| `Ctrl + D` | **Cerrar** la terminal (logout) |
| `Ctrl + Z` | **Suspender** el proceso actual → [[04.3 - Gestión de Procesos, Señales y Control de Trabajos]] |
| `Tab` | **Autocompletar** nombres de archivos y comandos |
| `Tab Tab` | Mostrar **todas las opciones** de autocompletado |

> [!tip] La tecla Tab es tu mejor amiga
> Presiona `Tab` para autocompletar nombres de archivos, directorios y comandos. Si hay varias opciones, presiona `Tab` dos veces para ver todas las posibilidades. Esto te ahorra **muchísimo** tiempo y evita errores de escritura.
> ```bash
> cd /ho[Tab]        → cd /home/
> cd /home/ju[Tab]   → cd /home/juan/
> ls /etc/apa[Tab]   → ls /etc/apache2/
> ```
