# 🔧 Modificación de Permisos (chmod)

## ¿Qué es `chmod`?

El comando `chmod` (**ch**ange **mod**e) es la herramienta para **modificar los permisos** de archivos y directorios en Linux. Existen dos métodos para usarlo: el **modo simbólico** (con letras) y el **modo octal** (con números). Ambos hacen exactamente lo mismo, solo cambia la forma de expresarlo.

> [!abstract] 🎛️ Analogía: El Panel de Control de Accesos
> Imagina un panel de seguridad en un edificio con interruptores para cada sala. Tienes dos formas de configurarlo:
> - **Modo Simbólico**: Dices instrucciones en lenguaje humano: "Añade acceso de lectura al grupo" o "Quita acceso de escritura a otros".
> - **Modo Octal**: Introduces un código numérico directo: "755" o "644", que el sistema traduce automáticamente a los permisos exactos.

---

## Método 1: Modo Simbólico (Letras y Operadores)

El modo simbólico usa **letras** para indicar a quién afecta el cambio y **operadores** para indicar qué hacer:

### Quién (Sujeto)

| Letra | Significado |
|-------|-------------|
| `u` | **User** — El propietario del archivo |
| `g` | **Group** — El grupo del archivo |
| `o` | **Others** — Todos los demás |
| `a` | **All** — Los tres a la vez (u + g + o) |

### Qué Hacer (Operador)

| Operador | Acción |
|----------|--------|
| `+` | **Añadir** un permiso |
| `-` | **Quitar** un permiso |
| `=` | **Establecer** exactamente estos permisos (sobrescribe los anteriores) |

### Qué Permiso

| Letra | Permiso |
|-------|---------|
| `r` | Lectura |
| `w` | Escritura |
| `x` | Ejecución |

### Ejemplos Prácticos del Modo Simbólico

```bash
# AÑADIR permiso de ejecución al propietario:
chmod u+x script.sh
# Antes: -rw-r--r--  →  Después: -rwxr--r--

# QUITAR permiso de escritura al grupo:
chmod g-w archivo.txt
# Antes: -rw-rw-r--  →  Después: -rw-r--r--

# ESTABLECER permisos exactos para otros (solo lectura):
chmod o=r documento.pdf
# Antes: -rw-r--rwx  →  Después: -rw-r--r--

# Añadir lectura y ejecución para TODOS:
chmod a+rx programa
# Antes: -rw-------  →  Después: -rwxr-xr-x

# Quitar TODOS los permisos de otros:
chmod o= privado.key
# Antes: -rw-r--r--  →  Después: -rw-r-----

# Combinar múltiples cambios separados por comas:
chmod u+x,g+r,o-rwx script.sh
# Añade ejecución al dueño, lectura al grupo, quita todo a otros

# Hacer un directorio accesible para todos:
chmod a+rx carpeta/

# Hacer un archivo completamente privado:
chmod go= secreto.txt
# Quita todos los permisos de grupo y otros
# Resultado: -rw------- (solo el dueño puede leer/escribir)
```

## Método 2: Modo Octal (Números)

El modo octal es más rápido y directo. Usa **tres dígitos** donde cada dígito es la **suma** de los valores de los permisos:

### La Tabla de Valores

| Permiso | Valor | Binario |
|---------|-------|---------|
| Lectura (r) | **4** | 100 |
| Escritura (w) | **2** | 010 |
| Ejecución (x) | **1** | 001 |
| Sin permiso (-) | **0** | 000 |

### Cómo Calcular

Cada dígito octal es la **suma** de los permisos que quieres activar:

```
rwx = 4 + 2 + 1 = 7    (todos los permisos)
rw- = 4 + 2 + 0 = 6    (leer y escribir)
r-x = 4 + 0 + 1 = 5    (leer y ejecutar)
r-- = 4 + 0 + 0 = 4    (solo leer)
-wx = 0 + 2 + 1 = 3    (escribir y ejecutar)
-w- = 0 + 2 + 0 = 2    (solo escribir)
--x = 0 + 0 + 1 = 1    (solo ejecutar)
--- = 0 + 0 + 0 = 0    (ningún permiso)
```

### Los Tres Dígitos

```
chmod  7   5   5   archivo.txt
       │   │   │
       │   │   └── Otros (o):  r-x = 4+0+1 = 5
       │   └── Grupo (g):  r-x = 4+0+1 = 5
       └── Usuario (u): rwx = 4+2+1 = 7
```

### Tabla de Combinaciones Octales Más Usadas

| Octal | Simbólico | Significado | Uso Típico |
|-------|-----------|-------------|-----------|
| **777** | `rwxrwxrwx` | Todos pueden todo | ⚠️ Inseguro, evitar en producción |
| **755** | `rwxr-xr-x` | Dueño: todo. Resto: leer/ejecutar | Programas, scripts, carpetas de proyectos |
| **750** | `rwxr-x---` | Dueño: todo. Grupo: leer/ejecutar. Otros: nada | Carpetas de equipo |
| **700** | `rwx------` | Solo dueño: todo | Scripts privados, carpetas sensibles |
| **666** | `rw-rw-rw-` | Todos: leer/escribir | ⚠️ Inseguro, archivos compartidos sin cuidado |
| **664** | `rw-rw-r--` | Dueño y grupo: leer/escribir. Otros: leer | Archivos de trabajo en equipo |
| **644** | `rw-r--r--` | Dueño: leer/escribir. Resto: leer | Archivos normales, configuraciones |
| **600** | `rw-------` | Solo dueño: leer/escribir | Claves SSH, archivos privados sensibles |
| **400** | `r--------` | Solo dueño: leer | Archivos de solo lectura ultra-privados |

### Ejemplos Prácticos del Modo Octal

```bash
# Hacer un script ejecutable por todos (755):
chmod 755 deploy.sh
# -rwxr-xr-x

# Archivo normal legible por todos (644):
chmod 644 README.md
# -rw-r--r--

# Archivo completamente privado (600):
chmod 600 ~/.ssh/id_rsa
# -rw-------

# Carpeta privada (700):
chmod 700 ~/secretos/
# drwx------

# Dar permisos totales temporalmente (777) — ¡cuidado!:
chmod 777 /tmp/compartido
# -rwxrwxrwx

# Permisos de equipo (770):
chmod 770 /proyecto/shared/
# drwxrwx---
```

## Modo Simbólico vs Octal: ¿Cuándo Usar Cada Uno?

| Situación | Mejor Método | Ejemplo |
|-----------|-------------|---------|
| Cambiar UN permiso específico | Simbólico | `chmod u+x script.sh` |
| Establecer TODOS los permisos de golpe | Octal | `chmod 755 script.sh` |
| Añadir ejecución sin tocar el resto | Simbólico | `chmod +x programa` |
| Configurar permisos exactos | Octal | `chmod 644 config.json` |
| Cambios complejos a múltiples niveles | Simbólico | `chmod u+rwx,g=rx,o=r` |

## Aplicar Permisos Recursivamente

```bash
# Cambiar permisos de una carpeta Y todo su contenido (-R = recursive):
chmod -R 755 proyecto/
# Aplica 755 a la carpeta Y a TODOS los archivos y subcarpetas dentro

# Caso común: Permisos diferentes para archivos y directorios:
# (Los directorios necesitan 'x' para poder entrar, los archivos no)

# Paso 1: Dar 755 a todos los directorios:
find proyecto/ -type d -exec chmod 755 {} \;

# Paso 2: Dar 644 a todos los archivos:
find proyecto/ -type f -exec chmod 644 {} \;

# Paso 3: Dar 755 solo a los scripts .sh:
find proyecto/ -name "*.sh" -exec chmod 755 {} \;
```

> [!tip] Truco con `find` + `chmod`
> La combinación `find` + `-exec chmod` es la forma profesional de aplicar permisos diferentes a archivos y directorios. Esto es muy habitual en servidores web donde los directorios necesitan `755` y los archivos `644`.

## Caso Real: Configurar un Servidor Web

```bash
# Situación: Has subido tu sitio web a /var/www/html
# Necesitas que Apache pueda leer los archivos pero que nadie los modifique

# 1. Directorios: 755 (Apache puede entrar y listar)
sudo find /var/www/html -type d -exec chmod 755 {} \;

# 2. Archivos: 644 (Apache puede leer, solo tú puedes editar)
sudo find /var/www/html -type f -exec chmod 644 {} \;

# 3. El propietario debe ser el usuario web:
sudo chown -R www-data:www-data /var/www/html
# chown se explica en → [[03.4 - Administración de Usuarios, Grupos y Propiedades]]
```
