
> [!abstract] Analogía del curso
> Imaginate que pedís comida a domicilio. La forma segura es ir directo al restaurante oficial. La forma peligrosa es pedirla a través de un delivery de dudosa procedencia que podría meterte cualquier cosa en la bolsa. Lo mismo pasa con las descargas de software: siempre desde el restaurante oficial, nunca desde el repartidor intermediario.

## 🔽 El Problema de los Instaladores Intermediarios

Cuando buscás "descargar VLC" o "descargar WinRAR" en Google, los primeros resultados que aparecen rara vez son el sitio oficial. Son **portales de descargas intermediarios**: páginas como Softonic, CNET, UptoDown, FileHippo… que actúan como un *delivery* entre el software original y vos.

¿Cuál es el riesgo real?

1. **El instalador web**: Estas páginas muchas veces no te dan el `.exe` directo del programa. Te dan un **pequeño instalador propio** que, cuando lo ejecutás, descarga el programa real Y además instala adware, barras de herramientas, modificadores del navegador, o directamente malware.
2. **Versiones desactualizadas**: Usan versiones antiguas del software que pueden tener vulnerabilidades ya conocidas y parchadas en las versiones modernas.
3. **Archivos modificados**: En el peor de los casos, el archivo descargado ya no es el original. Alguien metió mano y le inyectó código malicioso antes de subirlo al portal.

> [!danger] Regla de Oro de las Descargas
> **Siempre descargá desde el sitio oficial del desarrollador.** Sin excepciones. Si no sabés cuál es el sitio oficial, buscá el nombre del programa en Wikipedia o en su repositorio de GitHub. Nunca confíes en el primer resultado patrocinado de Google.

### ✅ Cómo Identificar una Descarga Oficial

- La URL debe ser el dominio principal del proyecto (ej. `videolan.org` para VLC, no `vlc-descarga.com.ar`).
- Verificá el **certificado SSL** (que sea HTTPS) y que el nombre de la organización en el certificado coincida.
- Si el programa es open source, buscá la sección **"Releases"** en su repositorio de GitHub oficial.
- Después de descargar, verificá el **hash SHA-256** del archivo si el sitio lo proporciona. Así sabés que el archivo no fue alterado en tránsito.

## 🙈 La Gran Mentira de Windows: Las Extensiones Ocultas

Esta es una de las configuraciones más peligrosas que tiene Windows activada por defecto y que muy poca gente conoce.

**Por defecto, Windows oculta las extensiones de los tipos de archivo conocidos.**

¿Qué significa esto en la práctica? Que si un archivo se llama `foto_vacaciones.jpg`, Windows te lo muestra como `foto_vacaciones` y dibuja un ícono de imagen al lado. Aparentemente parece una foto. Perfecto. ¿No?

El problema es cuando alguien te manda un archivo que en realidad se llama:

```
foto_vacaciones.jpg.exe
```

Como Windows oculta la última extensión conocida (`.exe`), te muestra el archivo como `foto_vacaciones.jpg` con el ícono que el creador del malware eligió (en este caso, el de una imagen JPG). Hacés doble clic pensando que vas a ver una foto y en realidad **estás ejecutando un programa malicioso**.

> [!danger] Esto no es teoría
> Esta técnica de enmascaramiento de extensiones es una de las más usadas para distribuir malware por correo electrónico y aplicaciones de mensajería. Un antivirus puede detectarlo… o puede no hacerlo si el archivo es suficientemente nuevo.

---

## 🔧 Cómo Activar "Mostrar Extensiones de Archivo" en Windows 10/11

**Método rápido (Windows 11):**
1. Abrí el **Explorador de Archivos** (`Win + E`).
2. Hacé clic en **"Ver"** en la barra superior.
3. Seleccioná **"Mostrar"**.
4. Activá la opción **"Extensiones de nombre de archivo"**.

**Método clásico (Windows 10/11):**
1. Abrí el **Explorador de Archivos**.
2. Hacé clic en **"Ver"** en la pestaña superior.
3. Marcá la casilla **"Extensiones de nombre de archivo"**.

**Método por Panel de Control:**
1. Buscá "Opciones del Explorador de archivos" en el menú de inicio.
2. Pestaña **"Ver"**.
3. **Desmarcá** la casilla que dice *"Ocultar las extensiones de archivo para tipos de archivo conocidos"*.
4. Aplicar → OK.

Desde ese momento, todos los archivos te mostrarán su extensión real. Si ves `documento.pdf.exe`, sabés inmediatamente que algo está mal.

## ⚠️ Tabla de Extensiones de Riesgo Extremo

Estas extensiones son **archivos ejecutables o de scripting** que pueden correr código en tu sistema. Nunca las abras si vienen de una fuente desconocida o inesperada.

| Extensión | Tipo | Riesgo |
|-----------|------|--------|
| `.exe` | Ejecutable de Windows | 🔴 Crítico |
| `.msi` | Paquete de instalación | 🔴 Crítico |
| `.bat` | Script de comandos | 🔴 Crítico |
| `.cmd` | Script de comandos (moderno) | 🔴 Crítico |
| `.ps1` | Script de PowerShell | 🔴 Crítico |
| `.vbs` | Script de Visual Basic | 🟠 Alto |
| `.js` | JavaScript (puede ejecutarse en el SO) | 🟠 Alto |
| `.hta` | Aplicación HTML ejecutable | 🟠 Alto |
| `.scr` | Protector de pantalla (ejecutable disfrazado) | 🟠 Alto |

> [!technical] Detalle técnico: ¿Por qué .ps1 es tan peligroso?
> PowerShell es una herramienta de administración del sistema increíblemente poderosa. Un script `.ps1` puede descargar archivos de internet, modificar el registro, crear usuarios administradores, deshabilitar el antivirus y exfiltrar datos, todo en cuestión de segundos. Los atacantes modernos lo usan masivamente porque muchas políticas de seguridad lo ignoran por considerarlo "una herramienta legítima de Windows".

## 🛡️ Mark of the Web (MotW): El Guardián Silencioso de Windows

Windows tiene un mecanismo de protección llamado **"Mark of the Web"** (Marca de la Web). Cada vez que descargás un archivo de internet (desde el navegador o por correo), Windows le agrega una etiqueta invisible llamada **Zone.Identifier** que indica que ese archivo viene de internet y no es de confianza.

Cuando intentás ejecutar ese archivo, Windows muestra un aviso de seguridad preguntándote si estás seguro. Es ese molesto cartel azul o amarillo que la mayoría de la gente cierra sin leer haciendo clic en "Ejecutar de todas formas".

### 🎭 El Truco del ZIP con Contraseña

Acá viene una de las técnicas más ingeniosas y sucias del malware moderno para evadir tanto el MotW como el escaneo de antivirus.

**El ataque funciona así:**

1. El atacante comprime el archivo malicioso en un `.ZIP` y le pone **contraseña**.
2. Te envía el ZIP por correo con un mensaje del estilo: "Te mando los archivos del proyecto, la contraseña es `2024`".
3. Cuando el correo llega, el servidor de correo y tu antivirus intentan escanear el ZIP, pero **no pueden leer su interior porque está encriptado con contraseña**. El escáner no tiene la clave y no puede ver lo que hay adentro.
4. Vos abrís el ZIP con la contraseña que te dieron, extraés el archivo malicioso…
5. Y aquí viene el detalle crítico: **los archivos extraídos de un ZIP con contraseña NO heredan el Mark of the Web**. Windows no sabe que vinieron de internet. Los trata como archivos locales de confianza.
6. El malware se ejecuta sin advertencias y sin que el antivirus haya tenido oportunidad de escanearlo previamente.

> [!danger] Esto se usa activamente hoy
> Esta técnica es especialmente común en ataques dirigidos a empresas (phishing corporativo). Si alguien te manda un ZIP con contraseña de forma inesperada, sospechá antes de abrirlo, sin importar quién parece ser el remitente.
