
> [!note] Definición
> Los **metadatos** son los *datos de los datos*: información adicional incrustada dentro de un archivo que describe sus propiedades, origen y contexto — sin ser visible en el contenido principal del archivo.

---

## ¿Qué son los metadatos?

Cada archivo digital contiene dos capas de información:

1. **El contenido visible**: la imagen que ves, el texto que lees, el vídeo que reproduces.

2. **Los metadatos ocultos**: información técnica sobre cómo, cuándo, dónde y con qué se creó ese archivo.

| Tipo de archivo | Metadatos típicos |
| --------------- | ----------------- |
| Foto (JPEG, PNG) | Cámara, fecha, hora, GPS, orientación, apertura, ISO |
| Documento (PDF, DOCX) | Autor, fecha de creación, fecha de modificación, software usado, historial de revisiones |
| Audio (MP3) | Artista, álbum, año, herramienta de grabación |
| Vídeo (MP4) | Cámara, resolución, GPS, duración, codec |

---

## El estándar EXIF: la huella de tu cámara

**EXIF** (*Exchangeable Image File Format*) es el estándar que los fabricantes de cámaras (incluyendo las cámaras de los teléfonos móviles) utilizan para incrustar información técnica en cada fotografía.

### ¿Qué contiene un EXIF típico?

```
Fecha y hora: 2024-03-15 14:23:07
Dispositivo: iPhone 15 Pro
Resolución: 4032 x 3024
Apertura: f/1.78
ISO: 100
Orientación: Horizontal
Software: iOS 17.3.1
──────────────────────────────────────
GPS Latitud: 40.4168° N
GPS Longitud: 3.7038° W
GPS Altitud: 650 m
──────────────────────────────────────
```

Los datos técnicos de la cámara (apertura, ISO, resolución) son relativamente inofensivos. Pero las **coordenadas GPS** son una localización exacta del lugar donde se tomó la foto — con precisión de metros.

## Demostración práctica: extraer ubicación de una foto

### El escenario

Cuando envías una foto por WhatsApp o Telegram, el comportamiento cambia según **cómo** la envíes:

| Método de envío | ¿Conserva EXIF? | ¿Conserva GPS? |
| --------------- | ---------------- | --------------- |
| **Como imagen** (galería → enviar) | ❌ No — comprime y elimina EXIF | ❌ No |
| **Como documento/archivo** (adjuntar → documento) | ✅ Sí — envía el archivo original intacto | ✅ **Sí** |

Si alguien te envía una foto **como documento**, recibes el archivo JPEG original con todos sus metadatos intactos, incluidas las coordenadas GPS exactas de donde se tomó.

### Cómo extraer las coordenadas

#### Método 1: Con herramientas online

1. Descarga la foto recibida como documento.

2. Sube la imagen a una herramienta como [exif.tools](https://exif.tools) o [jimpl.com](https://jimpl.com).

3. Busca los campos `GPS Latitude` y `GPS Longitude`.

4. Copia las coordenadas y pégalas en Google Maps.

#### Método 2: Desde el propio dispositivo

- **Windows**: clic derecho en la foto → Propiedades → pestaña "Detalles" → buscar "GPS".

- **macOS**: abrir con Vista Previa → menú Herramientas → "Mostrar inspector" → pestaña GPS.

- **Android**: abrir con Google Fotos → deslizar hacia arriba → ver mapa de ubicación.

#### Método 3: Con línea de comandos (ExifTool)
```bash
exiftool foto.jpg | grep -i gps
```
Resultado:
```
GPS Latitude : 40 deg 25' 0.48" N
GPS Longitude : 3 deg 42' 13.68" W
GPS Position : 40.4168 N, 3.7038 W
```

Esas coordenadas llevadas a Google Maps muestran **la ubicación exacta** donde se tomó la foto.

## El riesgo real

Imagina estos escenarios:

| Acción | Riesgo |
| ------ | ------ |
| Envías una foto de tu casa como documento | El receptor sabe exactamente dónde vives |
| Publicas una foto de tus hijos en un foro (formato original) | Cualquiera puede extraer la ubicación del colegio o del parque |
| Vendes algo online y envías fotos del producto como archivo | El comprador conoce tu dirección antes de que tú la compartas |
| Compartes una foto de vacaciones como documento | Confirmas que no estás en casa |

---

## Soluciones prácticas

### 1. Desactivar la geolocalización de la cámara

La solución más directa es impedir que la cámara grabe la ubicación en primer lugar:

- **iPhone**: Ajustes → Privacidad → Localización → Cámara → seleccionar "Nunca".

- **Android**: Abrir la app de Cámara → Ajustes → desactivar "Guardar ubicación" o "Etiquetas de ubicación".

### 2. Enviar como imagen, no como documento

Cuando compartas fotos por mensajería, envíalas desde la **galería** (botón de foto/imagen), no como documento adjunto. **La compresión que aplican WhatsApp y Telegram elimina los metadatos EXIF automáticamente por optimización(porque si no los archivos pesarían mucho y además por seguridad).**

```
 ✅ Enviar como imagen (galería) → EXIF eliminado
 ❌ Enviar como documento → EXIF intacto (incluye GPS)
```

### 3. Usar capturas de pantalla (screenshots)

Si necesitas compartir una imagen y quieres máxima seguridad:

1. Abre la foto.

2. Haz una captura de pantalla.

3. Envía la captura en lugar de la foto original.

La captura de pantalla es una imagen nueva generada por tu sistema operativo. No contiene los metadatos EXIF de la foto original (aunque sí contendrá los datos del propio screenshot — generalmente sin GPS si la captura se hace desde la galería).

### 4. Limpiar metadatos manualmente

Si necesitas enviar el archivo original pero sin metadatos:

- **Windows**: clic derecho → Propiedades → Detalles → "Quitar propiedades e información personal".

- **Herramientas online**: [exifcleaner.com](https://exifcleaner.com), [verexif.com](https://www.verexif.com).

- **Línea de comandos**:

 ```bash
 exiftool -all= foto.jpg
 ```

---

## Resumen

| Acción | ¿Segura? |
| ------ | -------- |
| Enviar foto como imagen por WhatsApp/Telegram | ✅ Sí (EXIF limpiado automáticamente) |
| Enviar foto como documento/archivo | ❌ No (EXIF intacto con GPS) |
| Publicar foto original en foros/webs | ❌ No (depende de si la plataforma limpia EXIF) |
| Enviar screenshot de la foto | ✅ Sí (imagen nueva sin EXIF original) |
| Desactivar GPS de la cámara | ✅ Sí (prevención desde el origen) |
