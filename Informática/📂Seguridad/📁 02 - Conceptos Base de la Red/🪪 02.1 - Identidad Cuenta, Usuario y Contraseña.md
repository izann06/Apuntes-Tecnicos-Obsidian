
> [!note] ¿Por qué empezar aquí?
> Estos tres conceptos se confunden constantemente, y esa confusión genera malas prácticas de seguridad. Definirlos con precisión es el primer paso para protegerlos correctamente.

---

## Definiciones exactas

### Cuenta (tu identidad digital completa)

La **cuenta** es el contenedor de toda tu identidad dentro de un servicio. Incluye:

- Tu perfil (nombre, foto, datos personales).

- Tu historial de actividad.

- Tus configuraciones y preferencias.

- Tus datos almacenados (correos, archivos, fotos, compras).

- Tus métodos de autenticación (contraseña, 2FA, sesiones activas).

**Analogía**: la cuenta es como la casa entera — paredes, muebles, objetos personales, cerradura y llave.

---

### Usuario (el identificador público)

El **usuario** (o *username*) es el nombre único que te identifica dentro de un servicio. Es la etiqueta pública que el sistema y otras personas usan para referirse a ti.

Puede adoptar diferentes formas según la plataforma:

| Servicio | Formato del usuario |
| -------- | ------------------- |
| Correo electrónico | `nombre@gmail.com` |
| Instagram | `@tu_nombre` |
| Discord | `nombre#1234` o nombre único |
| Foros / videojuegos | Nickname elegido |

**Características clave del usuario:**

- Generalmente es **público** o fácil de encontrar.

- **No es un secreto**: compartirlo no compromete tu cuenta por sí solo.

- Sirve para que el sistema sepa *quién dice ser* la persona que intenta entrar.

**Analogía**: el usuario es como el número de tu casa en la calle. Todo el mundo puede verlo, pero no por eso pueden entrar.

---

### Contraseña (la prueba de autenticidad)

La **contraseña** es el mecanismo que demuestra que tú eres realmente el dueño de la cuenta asociada a ese usuario. Es la respuesta a la pregunta:

> *"Dices ser este usuario. Demuéstralo."*

**Características clave de la contraseña:**

- Debe ser **secreta**: solo tú debes conocerla.

- Debe ser **única por servicio**: reutilizarla en múltiples sitios la convierte en un punto único de fallo (ver [[🏰 03.1 - La Muralla de las Contraseñas y Gestores]]).

- Es **solo el primer factor** de autenticación. Idealmente, no debería ser el único (ver [[🔐 03.2 - Doble y Múltiple Factor (2FA y MFA)]]).

**Analogía**: la contraseña es la llave de la casa. Si alguien la copia, puede entrar aunque no viva allí.

---

## La relación entre los tres

```
┌─────────────────────────────────────────────┐
│ CUENTA │
│ (Tu identidad digital completa) │
│ │
│ ┌──────────────┐ ┌──────────────────┐ │
│ │ USUARIO │ │ CONTRASEÑA │ │
│ │ (Quién eres) │ + │ (Prueba de que │ │
│ │ │ │ eres tú) │ │
│ └──────────────┘ └──────────────────┘ │
│ │
│ Datos, archivos, historial, config... │
└─────────────────────────────────────────────┘
```

- La **cuenta** es lo que proteges.

- El **usuario** es cómo te identificas.

- La **contraseña** es cómo demuestras que eres tú.

> [!important] Error común
> Muchas personas creen que proteger el "usuario" es importante y que compartirlo es peligroso. En realidad, el usuario casi siempre es público (tu email, tu @nombre). **Lo que debe ser secreto es la contraseña, y lo que se debe proteger con capas es la cuenta.**

---

## ¿Por qué importa entender esto?

Porque si no distingues entre estos conceptos, cometes errores como:

| Confusión | Error resultante |
| --------- | ---------------- |
| Creer que el usuario es secreto | No proteger la contraseña con suficiente cuidado |
| Creer que la contraseña = la cuenta | Pensar que cambiar la contraseña lo soluciona todo (ignorando sesiones activas, 2FA, emails de recuperación) |
| Creer que la cuenta = solo el login | Olvidar que la cuenta contiene datos valiosos más allí del acceso |
