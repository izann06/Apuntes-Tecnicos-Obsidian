## 🧠 Asociación de Datos Rápida para el Examen

Cuando el escenario del examen te hable de un tipo de dato o problema concreto, la respuesta suele ser directa:

| Tipo de Dato / Problema | Servicio de AWS a elegir |
| :--- | :--- |
| **Tablas / Excel** (Datos estructurados, Data Warehouse) | **Amazon Redshift** |
| **Fotos / Videos** (Datos no estructurados, Visión) | **Amazon Rekognition** |
| **Texto libre / Análisis de Sentimientos** (NLP) | **Amazon Comprehend** |
| **Creación de etiquetas** (Humanos en el bucle / *Human-in-the-loop*) | **Amazon SageMaker Ground Truth** |
| **Series Temporales** (Ventas o métricas a lo largo del tiempo) | **Amazon Forecast** |

## 🚀 Cheat Sheet: Categorías y Servicios Directos de AWS

| Categoría / Capacidad | Servicio AWS |
| :--- | :--- |
| **Plataforma ML Integral** (Desarrollo completo) | **Amazon SageMaker** |
| **Voz a Texto** (Transcripción de audio) | **Amazon Transcribe** |
| **Texto a Voz** (Voz natural / Neural) | **Amazon Polly** |
| **Traducción de idiomas** | **Amazon Translate** |
| **Visión Artificial** (Rostros, objetos, moderación) | **Amazon Rekognition** |
| **Extracción de Documentos** (Texto y tablas de PDFs/Escaneos) | **Amazon Textract** |
| **NLP** (Procesamiento de Lenguaje Natural, entidades, sentimiento) | **Amazon Comprehend** |
| **Chatbots e Interfaces conversacionales** | **Amazon Lex** |
| **Recomendaciones Personalizadas** | **Amazon Personalize** |
| **Detección de Fraude** (Bancario, registros falsos) | **Amazon Fraud Detector** |
| **Pronósticos de tendencias** (Métricas futuras) | **Amazon Forecast** |
