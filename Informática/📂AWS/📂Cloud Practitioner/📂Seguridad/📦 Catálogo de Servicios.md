**Tags:** #aws #cp-seguridad


- **AWS Identity and Access Management (AWS IAM):** Administrar de forma segura las identidades y el acceso a los servicios y recursos de AWS.
    
- **AWS IAM Identity Center:** Conecta tu origen de identidad de personal existente y administra de forma centralizada el acceso a AWS con un inicio de sesión único.
    
- **AWS Secrets Manager:** Almacena y administra de forma centralizada las credenciales, las claves de API y otros secretos.
    
- **AWS Systems Manager:** Administra nodos o puntos de conexión a escala en AWS y en entornos híbridos y de múltiples nubes.
    
- **AWS Shield:** Protege tu red y aplicaciones de los tipos de ataques DDoS más comunes y frecuentes.
    
- **AWS WAF:** Protege tu red y aplicaciones de las direcciones IP bloqueadas definidas por una ACL web.
    
- **AWS Key Management Service (AWS KMS):** Crea y administra claves criptográficas para cifrar y descifrar los datos.
    
- **Amazon Macie:** Certifica que los datos confidenciales se descubren y protegen en Amazon S3.
    
- **AWS Certificate Manager (ACM):** Centraliza y administra los certificados SSL/TLS que proporcionan cifrado de datos en tránsito.
    
- **Amazon Inspector:** Compruebe las aplicaciones para detectar vulnerabilidades de seguridad y desviaciones de las prácticas recomendadas de seguridad.
    
- **Amazon GuardDuty:** Supervisa continuamente el entorno de AWS con una detección inteligente de amenazas.
    
- **Amazon Detective:** Analiza las amenazas con visualizaciones interactivas contenidas en una vista unificada.
    
- **AWS Security Hub:** Añade los resultados de seguridad y organízalos en información procesable.
