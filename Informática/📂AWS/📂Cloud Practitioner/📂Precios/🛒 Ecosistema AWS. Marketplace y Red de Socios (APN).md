> [!summary] El Concepto Clave
> Para acelerar tu migración a la nube y no "reinventar la rueda", AWS te ofrece dos grandes recursos: **AWS Marketplace** (La tienda digital para comprar software de terceros) y la **Red de Socios de AWS / APN** (La red global para contratar empresas de consultoría y expertos tecnológicos que te ayuden a construir).

---

## 🛍️ 1. AWS Marketplace (La "App Store" Corporativa)

Si necesitas un Firewall avanzado, un panel de Inteligencia de Negocios o un modelo de Machine Learning ya entrenado, no tienes que programarlo tú mismo.

* **¿Qué es?** Es un catálogo digital selecto donde puedes buscar, probar, comprar y desplegar software de terceros que se ejecuta directamente en tu arquitectura de AWS.

* **Proveedores de Software Independientes (ISV):** Las empresas que venden su software aquí se denominan ISVs.

* **Las Ventajas:**

 * **Despliegue Rápido:** Puedes instalar software complejo en tus instancias EC2 con un par de clics mediante las AMIs (Imágenes de Máquina de Amazon) preconfiguradas del Marketplace.
 
 * **Modelos de Precios Flexibles:** Puedes pagar por horas (pago por uso), por suscripción anual o usar software gratuito de código abierto.
 
 * **Facturación Consolidada (¡Muy Importante!):** Cuando compras software en AWS Marketplace, no tienes que darle tu tarjeta de crédito al proveedor externo. **El coste de esa licencia de software se añade automáticamente a tu factura normal de AWS**.

* **Que hay:**

	**Software como servicio (SaaS):**
 
 - Aplicaciones empresariales, como herramientas de administración de proyectos
 
 - Herramientas de marketing, como las plataformas de interacción con clientes
 
 - Herramientas de colaboración, como los servicios de intercambio de archivos
 
 
 **Machine learning (ML) e IA:**
 
 - Modelos prediseñados para el reconocimiento de imágenes, el procesamiento del lenguaje natural y más
 
 - Algoritmos de ML para entrenar modelos personalizados
 
 
 **Datos y análisis:**
 
 - Plataformas de inteligencia empresarial para visualización e informes

## 🤝 2. Red de Socios de AWS (APN - AWS Partner Network)

Si el Marketplace es para descargar programas, la APN es para "contratar humanos" (empresas de tecnología y consultoría).

* **¿Qué es?** Un programa global de empresas que han demostrado a Amazon que son expertas utilizando AWS para crear soluciones.

* **¿Por qué acudir a un Partner?** Imagina que tienes una tienda de ropa y quieres usar Machine Learning para recomendar productos, pero no tienes ingenieros en plantilla. Buscas un *Socio Consultor* en la APN que se especialice en Retail y Machine Learning, y ellos construyen la arquitectura por ti.

* **Convertirse en un Partner:** Si tu empresa de informática decide unirse a la APN para vender sus servicios, AWS le otorga beneficios como:

 * Acceso a fondos de financiación y créditos para pruebas.

 * Formación técnica exclusiva y certificaciones.

 * Invitaciones a eventos y talleres de networking.

---

## 📊 Chuleta Resumen: Marketplace vs APN

| ¿Qué estás buscando? | Solución en AWS | Analogía |
| :--- | :--- | :--- |
| Comprar un **software**, un firewall o un panel de control prefabricado. | **AWS Marketplace** | Ir a la tienda a comprar una herramienta. |
| Contratar **expertos, consultores** o empresas para que te ayuden a migrar o programar. | **AWS Partner Network (APN)** | Contratar a un arquitecto y obreros para construir tu casa. |
