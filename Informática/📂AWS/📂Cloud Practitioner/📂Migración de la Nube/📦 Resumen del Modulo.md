**Tags:** #aws #cp-migracion-de-la-nube

| **Recurso**                                            | **Descripción**                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Las tres fases de la migración                         | Al hacer una migración a gran escala, normalmente hay tres fases: evaluación, traslado y, en la última fase, migración y modernización.                                                                                                                                                                                                                                                                              |
| AWS Cloud Adoption Framework                           | AWS CAF es un marco de trabajo que aporta la experiencia y las prácticas recomendadas de AWS a las empresas que se preparan para migrar a la nube de AWS. El marco de trabajo proporciona herramientas para ayudar a acelerar el proceso de migración, organizar los recursos y alinear la administración durante la transición.                                                                                     |
| Siete estrategias de migración (7 R)                   | Al migrar a la nube, hay siete estrategias de migración comunes que se pueden utilizar. Con reubicar, realojar, redefinir la plataforma, refactorizar, recomprar, retener y retirar.                                                                                                                                                                                                                                 |
| Evaluador de la migración                              | Evaluador de la migración es un servicio de evaluación de migración que te ayuda a crear un caso empresarial para la planificación y la migración a la nube de AWS. Lo hace mediante un enfoque basado en datos que analiza el estado actual y el estado objetivo, y desarrolla un plan de preparación para la migración con los costes proyectados de la nube.                                                      |
| AWS Application Discovery Service                      | Application Discovery Service descubre el inventario y las conexiones de los servidores locales. Reúne los detalles de configuración, rendimiento y conexión de los servidores y las bases de datos para crear un plan de migración detallado.                                                                                                                                                                       |
| AWS Application Migration Service                      | Application Migration Service es una herramienta para migrar y mejorar tus aplicaciones locales y basadas en la nube. Ayuda a simplificar, acelerar y reducir el coste de la migración y modernización de las aplicaciones.                                                                                                                                                                                          |
| AWS Migration Hub                                      | Migration Hub es un centro único que te guía desde el descubrimiento hasta la evaluación, la planificación y la implementación de la migración. Proporciona herramientas, orientación y recomendaciones automatizadas para colaborar con tu equipo y hacer un seguimiento de la migración.                                                                                                                           |
| AWS Database Migration Service (AWS DMS)               | AWS DMS permite migrar las bases de datos de forma rápida y segura a la nube de AWS. Proporciona una forma de planificar, evaluar, convertir y migrar bases de datos, incluso con almacenes de datos, en una herramienta central.                                                                                                                                                                                    |
| Herramienta de conversión de esquemas de AWS (AWS SCT) | AWS SCT es un servicio que permite convertir esquemas de bases de datos y objetos de código (como procedimientos, vistas y funciones almacenados) de un motor de base de datos a otro.                                                                                                                                                                                                                               |
| AWS DataSync                                           | AWS DataSync se ha diseñado específicamente para automatizar y acelerar las migraciones de datos seguras. DataSync administra las cargas de trabajo de movimiento de datos con limitación del ancho de banda, programación de la migración, filtrado de tareas e informes de tareas. También proporciona una rápida replicación de los datos.                                                                        |
| AWS Transfer Family                                    | Transfer Family permite administrar y compartir datos sin problemas mediante transferencias de archivos sencillas, seguras y escalables. Este servicio proporciona un soporte completamente administrado para transferencias seguras de archivos a través de SFTP, FTPS, FTP y otros. Te ayuda a transferir archivos directamente hacia y desde los servicios de almacenamiento de AWS, como Amazon S3 y Amazon EFS. |
| AWS Direct Connect                                     | Direct Connect es un servicio de nube que puedes usar para establecer una conexión de red privada y exclusiva entre la red local y AWS.                                                                                                                                                                                                                                                                              |
| AWS Snow Family                                        | Los dispositivos AWS Snowball Edge Storage Optimized son una excelente solución para la migración de datos sin conexión cuando la conexión a internet puede no ser una opción. Los dispositivos Snowball Edge Storage Optimized ofrecen almacenamiento de alto rendimiento y permiten simplificar las migraciones de datos de varios petabytes desde ubicaciones locales a AWS.                                      |
