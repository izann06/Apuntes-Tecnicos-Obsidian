## 1. La Nube de Consumo (SaaS)

**Ejemplos:** OneDrive, iCloud, Google Drive, Dropbox.

Esto es lo que usamos como usuarios finales. 

> [!abstract] Analogía
> Imagina que es como **alquilar un trastero o un apartamento amueblado**.

- **¿Para qué sirve?** Para guardar fotos, documentos y archivos.

- **¿Cómo funciona?** Tú no sabes qué servidores hay detrás, ni qué sistema operativo usan, ni cómo se mantienen. Solo ves una carpeta donde arrastras archivos.

- **Limitación:** No puedes usar iCloud para crear una red social, ni para procesar millones de datos bancarios, ni para programar una Inteligencia Artificial. Solo sirve para lo que fue diseñado: **almacenar y sincronizar**.

---

## 2. La Nube de Infraestructura (IaaS / PaaS)

**Ejemplos:** AWS (Amazon Web Services), Azure (Microsoft), Google Cloud (GCP).

Esto es lo que usamos para estudiar e implementar arquitectura. 

> [!abstract] Analogía
> Siguiendo la analogía anterior, esto es como **alquilar un terreno con suministro eléctrico, agua y herramientas industriales**.

- **¿Para qué sirve?** Para **construir** cosas. Aquí es donde viven Netflix, Instagram o el sistema de tu banco.

- **¿Cómo funciona?** AWS te da las piezas de LEGO sueltas (servidores vacíos, bases de datos en blanco, redes, potencia de cómputo). Tú decides cómo conectarlas para crear una aplicación.

> [!info] Dato curioso
> ¡OneDrive y iCloud viven dentro de estas nubes! Por ejemplo, gran parte de lo que guardas en **iCloud** de Apple se almacena en realidad en los servidores de **Google Cloud** y **AWS**. Apple les paga a ellos para usar su infraestructura.

## Comparativa rápida para que no se te olvide

| Característica | OneDrive / iCloud (SaaS) | AWS / Azure / Google Cloud (IaaS/PaaS) |
| :--- | :--- | :--- |
| **Usuario** | Persona común, estudiante, oficina. | Programadores, Ingenieros, Empresas. |
| **Función** | Guardar y compartir archivos. | Crear software, webs y procesar datos. |
| **Control** | Muy bajo (solo subes archivos). | Total (tú configuras todo el servidor). |
| **Analogía** | Es el **producto terminado** (el pan). | Es la **maquinaria de la panadería** (hornos, harina, logística). |
