- **Amazon Comprehend:** Utiliza el procesamiento del lenguaje natural para extraer información clave de los documentos.
    
- **Amazon Polly:** Convierte el texto en un discurso realista.
    
- **Amazon Transcribe:** Convierte el discurso en texto.
    
- **Amazon Translate:** Traduce el texto en varios idiomas.
    
- **Amazon Kendra:** Utiliza el procesamiento del lenguaje natural para consultar de forma inteligente el contenido empresarial.
    
- **Amazon Rekognition:** Identifica objetos y actividades en imágenes y vídeos.
    
- **Amazon Textract:** Puedes detectar y extraer texto mecanografiado y escrito a mano en documentos.
    
- **Amazon Lex:** Incorpora interfaces de conversación de voz y texto a las aplicaciones.
    
- **Amazon Personalize:** Añade recomendaciones personalizadas de clientes a las aplicaciones.
    
- **Amazon SageMaker AI:** Crea, entrena y despliega tus propios modelos de ML sin preocuparte por la infraestructura.
    
- **Amazon SageMaker JumpStart:** Despliega soluciones de ML previamente entrenadas, como visión artificial, PNL y datos tabulares, con solo unos pocos clics.
    
- **Amazon Bedrock:** Ajusta e integra sin problemas grandes modelos fundacionales de Amazon y empresas emergentes líderes de IA en tus aplicaciones de AWS con una sola API.
    
- **Amazon Q Business:** Puedes responder preguntas y resolver problemas utilizando los datos y la experiencia que se encuentran en los repositorios de información de la empresa.
    
- **Amazon Q Developer:** Agiliza el desarrollo con recomendaciones de código.
    
- **Amazon Kinesis Data Streams:** Puedes ingerir terabytes de datos de streaming en tiempo real.
    
- **Amazon Data Firehose:** Puedes ingerir y entregar datos en cuestión de segundos a varios consumidores, como lagos de datos y almacenes.
    
- **Amazon S3:** Puedes almacenar cantidades prácticamente ilimitadas de todos los tipos de datos con esta conocida opción de lago de datos.
    
- **Amazon Redshift:** Almacena petabytes de datos estructurados o semiestructurados en este servicio de almacenamiento de datos. Analiza grandes conjuntos de datos almacenados mediante consultas SQL complejas.
    
- **Catálogo de datos de AWS Glue:** Proporciona metadatos a varios servicios de análisis con este repositorio centralizado.
    
- **AWS Glue:** Puedes procesar los datos utilizando el catálogo de datos de AWS Glue como referencia.
    
- **Amazon EMR:** Puedes procesar cargas de trabajo de big data con marcos de trabajo conocidos como Apache Spark.
    
- **Amazon Athena:** Puedes usarlo para analizar varios orígenes de datos alojados en cualquier lugar con una única consulta SQL.
    
- **Amazon QuickSight:** Consulta los datos mediante la creación de paneles interactivos con o sin experiencia.
    
- **Amazon OpenSearch Service:** Consulta y supervisa el análisis de datos en tiempo real con búsquedas de palabras clave o NLP.
