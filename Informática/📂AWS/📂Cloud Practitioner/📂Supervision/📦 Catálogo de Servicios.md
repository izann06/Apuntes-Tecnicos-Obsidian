**Tags:** #aws #cp-supervision


- **Amazon CloudWatch:** CloudWatch supervisa los recursos de AWS y las aplicaciones que se ejecutan en AWS en tiempo real. Con CloudWatch, obtienes visibilidad de todo el sistema sobre el uso de los recursos, el rendimiento de las aplicaciones y el estado de funcionamiento.
 
- **AWS CloudTrail:** CloudTrail permite la auditoría, la supervisión de seguridad y la solución de problemas operativos. CloudTrail registra la actividad de los usuarios y las llamadas a la API en los servicios de AWS como eventos. Los eventos de CloudTrail ayudan a responder a la pregunta “¿Quién hizo qué, dónde y cuándo?”.
 
- **AWS Artifact:** AWS Artifact es un portal de autoservicio que proporciona acceso bajo demanda a la documentación de seguridad y conformidad de AWS, incluidos informes, certificaciones y acuerdos.
 
- **AWS Config:** AWS Config es un servicio para evaluar, auditar y examinar las configuraciones de los recursos de AWS.
 
- **AWS Audit Manager:** Audit Manager es un servicio para auditar continuamente el uso de AWS con el fin de agilizar la evaluación de riesgos y conformidad.
 
- **AWS Organizations:** Organizations te ayuda a administrar y gobernar el entorno de forma centralizada a medida que creces y escalas los recursos de AWS. Te ayuda a administrar las políticas de los grupos de cuentas y a automatizar la creación de cuentas.
 
- **AWS Control Tower:** Con AWS Control Tower se pueden aplicar y administrar las reglas de gobernanza para la seguridad, las operaciones y la conformidad a escala en todas las organizaciones y cuentas en la nube de AWS.
 
- **AWS Service Catalog:** Con Service Catalog se puede crear, compartir y organizar a partir de un catálogo seleccionado de recursos de AWS. Puedes desplegar herramientas de seguridad y recursos de red básicos para las nuevas cuentas de AWS para poder gestionarlas de manera sistemática.
 
- **AWS License Manager:** License Manager es un servicio que te ayuda a administrar las licencias de software y ajustar los costes de licencias.
 
- **AWS Trusted Advisor:** Trusted Advisor ayuda a optimizar los costes, aumentar el rendimiento, mejorar la seguridad y la resiliencia, y operar a gran escala en la nube. Evalúa continuamente el entorno de AWS mediante comprobaciones de las prácticas recomendadas en esas categorías y recomienda acciones para corregir las desviaciones de dichas prácticas.
 
- **AWS Health:** AWS Health es el origen de datos para los eventos y cambios que afectan a los recursos en la nube de AWS. AWS Health avisa sobre los eventos de servicio, los cambios planificados y las notificaciones de la cuenta para ayudar a administrar y tomar medidas.
 
- **Analizador de acceso de AWS IAM:** El Analizador de acceso de IAM ofrece funciones para establecer, verificar y ajustar los permisos de seguridad para lograr los estándares de seguridad con mínimo privilegio.
